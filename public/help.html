◈ contour打开编辑器 ↗

开始画，也帮我们把它变得更好。

Contour 试用版 · 矢量线稿、视角快照与姿态录制。建议在电脑浏览器中使用鼠标和键盘操作。

第一次使用

  1. 首次打开会载入基础脸模并进入绘制间，直接继续编辑。顶部「载入基础脸模」也可手动打开，撤销可返回原工程。已有浏览器存档会恢复自己的进度；也可点「打开」导入其它 JSON。
  2. P 钢笔画线，V 选择整笔，A 编辑端点与 handle；右侧管理图层和属性。
  3. Ctrl / ⌘ + Z 撤销；画好一个姿态后保存为快照，再到录制间指定 yaw / pitch、对齐姿态。
  4. 用「保存 JSON」把完整工程存到自己的电脑。

作品保存在你这里

自动存档保存在当前浏览器；网站没有云端作品同步。别人的操作不会改变你的画。

本机开发网址、线上网址、不同浏览器的存储各自独立。换地方继续画，请导出并打开 JSON。

清理浏览器数据或隐私模式可能丢失自动存档。重要作品请定期保存 JSON。

网站升级后先保存作品，再刷新页面。顶部会显示当前软件版本。

English quick guide

Use a desktop browser with a mouse and keyboard. The first visit opens the starter face in Drawing Room. Later visits restore your own project; P draws curves, V selects a stroke and A edits nodes. Ctrl/Cmd+Z undoes. Save a pose snapshot, then place it in Recording Room and assign yaw/pitch.

Your projects stay in this browser; there is no cloud project sync. Export JSON regularly and before refreshing for an update. For feedback, send the inviter your app version, browser/OS, workspace, reproduction steps, expected/actual result, a screenshot and a shareable JSON if available.

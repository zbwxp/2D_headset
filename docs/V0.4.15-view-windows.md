# V0.4.15 — 三主窗口 UI

第一阶段 UI checkpoint 为 26a916a；用户随后确认屏幕空间 mask 方案，现已接入真实 silhouette。

## 行为
- 顶部「主窗口」开关分别显示 2D、Contour、3D，至少保留一个。
- 默认 2D + 3D；三窗时依次为 2D / Contour / 3D。
- 单窗、双窗自动分配可用空间；「窗口比例」可调整可见窗口相对宽度。
- 窄屏使用纵向排列，不做 docking。
- 显隐和比例保存在独立 localStorage key，不进入 project JSON 或 geometry Undo。
- 隐藏窗口卸载其渲染资源；重开 3D 恢复此前 position/target。
- 3D OrbitControls 将 position/target/quaternion 发布到独立 display store。
- Contour 显示当前 3D 的正交视线方向；3D 隐藏时保留最后方向。
- Contour 只读、白底黑线，从最终曲面投影 union mask 提取外部轮廓。
- 现有 2D 编辑、参考图与 Patch Fullness 数学不变。

## 真实 silhouette 管线

HeadShell Final Surface → Orthographic Projection → Union Mask → Outer Boundary。
使用现有 BasePatch + Fullness 的 tessellate；固定每边 24 subdivisions
（quad 1152 / tri 576 triangles），mask 固定 768×768，均不受编辑窗口精度影响。

正交基取 3D quaternion 的 right/up；不读取 FOV、距离或相机平移。
使用最终几何的世界包围中心和半径统一适配画框，窗口 resize 只缩放 SVG 显示。
同一几何及朝向得到确定结果；3D dolly 不改变轮廓。
Contour 关闭后 Worker 终止；3D 隐藏后共享 pose 保留。

三角形 raster 使用双面 union coverage，因此 seam、内部三角边及背面重复覆盖不出线。
从 mask 边缘 flood-fill 外部背景；仅追踪前景和外部背景的界面。
内部空洞不描边，外部缺口和分离区域保留。不修改或补齐 source geometry。
输出为闭合像素边界 polyline，仅合并共线段，不做 Bézier fitting 或造型修正。

采样、mask 和追踪均在独立 Web Worker 运行。
source geometry 改变才重建 tessellation；相机改变复用 mesh。
最多一个在途任务，后续朝向只保留最新请求，避免累积过时计算。
旧 geometry revision 的结果丢弃。旋转中允许显示最近完成帧，并标记「更新中」。

每个 source triangle 保留 patchId/triangleId 及世界顶点，便于后续增加深度/ID buffer。
本版不提供 pixel-to-Patch picking，也不持久化 mesh、mask 或 contour。
无效 Patch 会跳过并显示数量及原因；无有效面或当前方向无覆盖时显示空状态。

# V0.4.15 — 三主窗口 UI

本次 checkpoint 只包含三窗口架构及 3D 相机同步接口。
Contour 的实际 silhouette evaluator 尚未接入，界面明确显示「轮廓计算器待接入」。
请求正文的「实时派生轮廓」与末尾「先搭 UI，之后接 evaluator」存在范围差异，已向用户确认。

## 行为
- 顶部「主窗口」开关分别显示 2D、Contour、3D，至少保留一个。
- 默认 2D + 3D；三窗时依次为 2D / Contour / 3D。
- 单窗、双窗自动分配可用空间；「窗口比例」可调整可见窗口相对宽度。
- 窄屏使用纵向排列，不做 docking。
- 显隐和比例保存在独立 localStorage key，不进入 project JSON 或 geometry Undo。
- 隐藏窗口卸载其渲染资源；重开 3D 恢复此前 position/target。
- 3D OrbitControls 将 position/target/quaternion 发布到独立 display store。
- Contour 显示当前 3D 的正交视线方向；3D 隐藏时保留最后方向。
- Contour 只读、白底，不投影结构线冒充 silhouette。
- 现有 2D 编辑、参考图与 Patch Fullness 数学不变。

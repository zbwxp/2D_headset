# V0.9.5 — Chin Scaffold

## 使用

在 HeadSet 左侧展开「下巴辅助壳」，点击「创建下巴辅助壳」。旧项目不会自动增加这块面，也不会替换已有下巴 Patch。

折叠标题显示当前项目状态：未创建、默认形、曲线约束中、已隐藏或约束需调整。展开未创建的模块会说明创建和接入已有曲线的步骤。

这是一个位于 HeadFrame 局部坐标中的连续下半壳，左右严格对称。默认提供下巴前尖、颌底中心、前颈中心、前后横弧中心、左右挂接点，以及中线、前后横弧、侧连接弧和前后开口弧。内部缝线是结构参考，不是独立面的接缝。

- 宽度、深度、高度三个尺寸参数均为 `0.01R–0.1R`，`R = HeadFrame.radiusX`，默认分别为 `0.06R / 0.05R / 0.03R`。宽和深表示完整跨度，高表示下半壳从开口到底部的高度；鼓出参数在深度范围内分配形状，不另外放大深度。位置 Y/Z 仍使用头壳原来的归一化坐标。
- 新增「下巴俯仰」`−90°–90°`，默认 `0°`。绕自身中心、模型局部 X 轴旋转；正值抬起前侧，负值压低前侧。先在统一 R 尺度下旋转，再应用 HeadFrame 朝向，头壳 XYZ 比例不同时也不会产生旋转拉伸。取消旧核中写死的 `−0.08 × q.z` 高度偏移。
- 尺寸、位置、俯仰、圆润度、前后鼓出、颈部收窄均可用滑条或双击数值输入。尺寸方向键步长 `0.001R`，俯仰步长 `1°`；圆润度改变下部轮廓的收尖程度，不等价于高度。
- 在「骨架线约束」中选择对应位置的独立 HeadSet 开放曲线，作为左右对称的修形约束。中央端点必须在中线；多个约束相交的位置必须一致。
- 「创建控制线」把当前骨架弧拟合为普通、独立的 3D cubic Bézier，并立即绑定。之后使用现有的端点、两个手柄和 XYZ 滑条编辑。
- 「移除约束」只释放该槽位，保留其它约束。删除源曲线也释放该约束；全部移除后回到当前参数定义的默认壳。绑定不会改写原曲线。
- 骨架弧支持 ON_CURVE 点、CurveSpan、普通 Free Curve endpoint 和 Patch boundary；骨架的真实交点具有多宿主成员关系。
- 「辅助面定位点」点击下巴壳会生成依附下巴壳的点，而非头部椭球点。位置保存为下半球域中的单位方向，随壳体和 HeadFrame 更新；这些点目前为固定域锚点，可复制为空间点。
- 所有源变化支持 Undo/Redo 和 Save/Load；显示、选择和隐藏沿用现有对象机制。

## 几何与依赖

`ChinScaffold` 只保存参数、显示开关，以及每个槽位的源 Curve ID、遍历方向和镜像标记。显示 mesh、拟合矩阵与系数不持久化。

默认核是经过比例、鼓出和后部收窄修形的下半椭球。约束曲线按归一化弧长取样25点，映射到固定的语义弧；用 compact C2 Wendland RBF 求一个对称的位移场。所有骨架弧和语义点都从同一个最终曲面求值。

尺寸和俯仰控制默认核；若已有外部曲线约束，继续尊重这些源线的位置，不会悄悄移动源线。解除约束后可看到完整的参数化旋转结果。

`ChinScaffold.version = 2` 保存统一 R 尺度和俯仰。读取旧版 version 1 时，转换旧的各轴尺寸到统一 R，按比例缩到新范围，保留点线 ID 和绑定。旧版缺少的俯仰取 0；新数据严格验证范围，不在正常 Save/Load 中再次缩放。

约束是采样拟合，不宣称整条外部 cubic 与壳体逐点完全相同。需要作为精确 Patch 边界时，引用最终派生的骨架弧/区间。复制骨架为控制线也是单 cubic 近似，可能有轻微形状变化。

依赖方向为 `独立源 Curve → chin:head → 派生点/骨架弧 → 下游 Curve/Patch`。不能把依附此壳的曲线反过来作为驱动；绑定时检测这种反馈并拒绝。删除源 Curve 不沿软约束连带删除整个模板。

一个共享顶点网格覆盖整个下半球，极点和周向闭合位置共享拓扑。Contour 沿用现有提取和遮挡算法；只把真实外缘作为 open boundary。普通 Patch 复用同一外缘区间时，该区间按现有共享边规则抑制。

## 本版范围与保护

这是局部语义壳，不改写 Tri/Quad/Loop Patch evaluator 或 Smooth solver。壳体内部平滑；外部普通 Patch 与壳体之间尚未自动求解 G1。也不保证复杂约束下所有视角的 Contour 都稳定。

冲突交点、中线违规、约束造成明显局部折返/塌缩时会给出 diagnostic，显示默认核以便修正；不会把损坏的拟合结果默认为成功。检测是离散网格上的保守检查，不是全局单射证明。

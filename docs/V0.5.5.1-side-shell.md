# V0.5.5.1 Convex Side Shell

The radial profile now interpolates between the flatter convex graph and sphere:

- p = max(6, 1/c²), q = (1-c²)/c
- flat = c + q (1-rho^(p+1))/(p+1)
- sphere = sqrt(1-(1-c²)rho²)
- x = (1-roundness) flat + roundness sphere

Both radial derivatives are nonpositive and second derivatives nonpositive. For the adaptive p, flat stays below sphere throughout the supported c range. Reflection supplies the left side and HeadFrame transforms are applied afterward. Helmet domain and Ring topology are unchanged.

Scaffold schema version 2 replaces convexity with roundness (default 0.5). Version 1 resets only the old shape parameter to this default; preserves sidePosition, visibility, anchor height, identities and offsets. Apex role IDs remain stable, while stock display names become 侧壳上锚点. Height belongs to the point inspector and does not change the surface cache key. Optional XYZ offset still follows the surface-derived base anchor.

Tests sample c=0.1,0.2,0.3,0.4,0.75,0.95 and roundness=0,.25,.5,.75,1. Numerical first/second derivatives, boundary value/tangent and monotonic interpolation are checked. A 20-image contour matrix covers front/30/45/side/top and four roundness settings. Open-rim concavities remain intentional domain boundaries, not side-surface curvature failures.

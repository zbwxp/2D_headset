# V0.4.0 — Basic Surface Patch

基线：v0.3.9-patch-prep / d783faa。开发分支：v0.4.0-basic-surface-patch。
项目数据采用用户的调整版.json，原始副本位于 artifacts/basic-patch/adjusted-source.json（50 点、66 边）。不修改其点坐标、控制柄、Plane、参考图、锁定状态或语义顺序。

## 操作

侧栏「曲面 Patch」点击「绘制面」，在画布或结构线列表选择 3 / 4 条现有边。第三条闭合立即创建，否则等第四条。成功后继续绘制；再次点已选边取消该选择；四条非法时保留选择并显示原因；Esc 或退出按钮退出。

左右自动成对，自对称闭环只创建一个面。侧栏选择/删除 Patch，不占 viewport picking。删除边界线时级联删除依赖面及镜像侧，Undo 可恢复。删除面不删除点线。

2D 全局不透明度默认 90%，3D 独立默认 70%。显示设置保存在 patchDisplay，修改不记录 geometry history，Undo/Redo 保留当前不透明度。

## Source 与 derived

SurfacePatch 保存 id、type、boundaryEdgeIds，以及可选 mirrorPartnerId / canonicalId。

闭环通过 endpoint UUID 验证：3/4 条互异边，每个顶点度数为二，形成单一连续闭环。遍历方向与起点确定性派生，不根据屏幕位置推断。重复闭环拒绝；共享边允许。

Quad 使用 Coons 边界混合减双线性项。
Tri 使用重心坐标：线性三角面加三条边的曲线偏移修正；边 i→j 的偏移权重为 (lambda_i+lambda_j)^2，边上参数为 lambda_j/(lambda_i+lambda_j)。在任意边上精确还原对应 cubic。顶点处零分母项取零，不添加 semantic diagonal。

镜像侧直接镜像 canonical evaluator 的最终世界坐标。自对称闭环根据顶点镜像置换映射参数并对称化，测试边界仍精确匹配。

渲染使用 24 段参数网格，临时三角形不是 source，不导出到 JSON。用户仍只编辑 Node / Curve。

## 显示

2D/缩略图：曲面三角形按当前相机深度由远到近 alpha 合成；Curve 分段与投影三角形做重心深度比较，每个前方 Patch 将线强度乘以 (1-opacity)，前方线不衰减。原 SVG cubic hit path 保留，Patch 图层 pointer-events:none。Landmark 保持最上层。透明度 0 时所有曲线恢复完整强度。

3D：双面着色网格，三角形随相机排序，透明材质不写深度；结构线使用正常 depth test，后方线由曲面 alpha 混合覆盖；点最后绘制。修复从零面开始添加面时 normal buffer 长度需要重新分配的问题。

这不是完整 OIT；交叉透明片可能存在排序误差。显示网格及线遮挡都是有限采样近似，数学 evaluator 的边界则精确。大量 Patch 的 SVG 图元数会增加；本版本未加入 LOD 或全局加速结构。

## 状态

有限且非零面积的曲面尽可能显示。局部法向相对平均法向反转时给出可能折叠 warning，不隐藏。这是启发式提示，不是完整自交判定，也不保证检测所有折叠。

仅非有限求值、近零面积或 evaluator 异常为 INVALID；保留 source record，恢复后自动显示。warning / invalid / mesh 不持久化。

旧 JSON 缺省无 Patch；有 Patch 的文件校验闭环、类型、唯一性与镜像关系。已有 Smooth 字段继续忽略。

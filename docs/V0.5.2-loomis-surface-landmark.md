# V0.5.2 — Loomis Surface Landmark

## Source and evaluation

Existing SemanticLandmark gets placement `{kind:'ON_LOOMIS_SURFACE',hostFrameId:'head',direction:Vec3}`. `direction` is unit length in normalized Loomis sphere space. No world/relative position, region ID or tessellation data is stored. Evaluation uses `toHead(project, unitDirection(direction))`. Missing Frame, invalid directions and surface ViewLocks reject on load. Old files keep their existing migration.

LEFT/RIGHT retain existing SemanticLandmark identities and mirrorPartnerId. Editing either side atomically updates its partner by `(-x,y,z)` in normalized space before frame transform. CENTERLINE uses x=0 and one normalized sagittal-circle parameter. Duplicate/Rename/Delete reuse landmark management.

## UI

Loomis 辅助 → 创建球面定位点 → click inside the ellipsoid in 3D (visible region is not required). Optional 中线点 creates a sagittal-circle point. Creation is one-shot; Esc cancels. Drag a surface point in 3D to update its direction. Ray miss holds the last valid point. Surface Inspector exposes derived Horizontal/Vertical angles (or middle-circle angle); NumericSlider supports direct entry. Angles are not persisted. 2D supports display/selection/curve-endpoint authoring, not spatial dragging of these points.

## Analytic picking

Inverse frame transform maps the camera ray into unit-sphere coordinates. Solve `a*t²+2*b*t+c=0` with stable roots and choose the nearest nonnegative intersection. Tangent discriminants use a scale-aware tolerance; degenerate rays/misses do not update source. Mesh or Region barycentric coordinates are never used.

## Dependencies and history

Frame → surface Point → incident Curve → Patch uses the existing dependency graph and evaluator. Direction edits touch only the selected pair and its descendants. Region has no edge to Point. Section deletion removes dependent Regions but preserves surface points and their curves. Existing relative handles and fullness are retained during followEndpoints.

Creation, pointer drag, Inspector change and deletion use existing history. Pointer up/cancel/lost capture, window blur, document hide and component cleanup end a drag session. Surface points bypass spatial ViewLock solving and do not receive projection locks.

## Validation

221 unit tests; 5 browser regressions covering actual 3D create/drag, undo/redo, delete/undo, Inspector and reload, plus Section, mixed Patch and Region creation. Unit coverage includes transformed/thin/tangent/missed rays, missing host, normalized direction, centerline, symmetry, incremental descendants, Patch deformation, Region/Section independence and source serialization. Production build passes.

Limits: no 2D surface creation/drag, surface offset or composite ON_CURVE+surface constraint. Inspector longitude can wrap visually at ±180°; the unit-vector source and 3D editing have no longitude seam.

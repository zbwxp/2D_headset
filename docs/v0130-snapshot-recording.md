# V0.13.0 — 快照录制间

录制间接收 Drawing Room 快照，在 HeadFrame-local yaw / pitch 下记录完整矢量姿态和整体二维平移。曲线、端点、控制柄、填充、显示区间的编辑均在绘制间完成。

## 操作

1. 在绘制间保存或更新命名快照。快照本身仍不绑定角度。
2. 进入录制间，选择快照，借助头壳参考、Yaw / Pitch 滑条和视角地图定位角度。
3. 点击「录入此视角」。同角度已有记录时按钮明确显示「替换此视角」。
4. 点击左侧姿态或地图绿点返回该记录。在「平移姿态」模式拖动左画布，或输入 X / Y 调整整体位置。输入过程中左右画布实时预览；Enter / 失去焦点确认，Esc 取消。每次拖动或数值编辑各为一次 Undo transaction。
5. 「旋转视角」模式拖动左画布改变 yaw / pitch；右键或 Shift 拖动平移观察画布，滚轮缩放。观察缩放和平移不写入姿态。
6. 滑条的数值可双击输入。姿态属性中的角度输入修改该记录的绑定角度；下方滑条仅导航，不创建或修改记录。
7. 回绘制间编辑后点击「更新当前快照」，所有引用该快照的录制姿态立即自动同步，无需再进录制间手动刷新。各姿态角度、平移、自定义名称和头壳参考大小保留。尚未存入快照的绘制草稿不参与录制，另存新快照也不替换其它快照的引用。
8. 删除录制姿态不删除原快照；原快照删除后，保留最后同步内容，并在姿态属性提示来源已删除。保存 JSON / 自动保存与 Undo / Redo 均包含录制结果。

## 覆盖与显示

- 正负 yaw 分别记录；不把已绘制的整脸自动镜像。技术范围 yaw ±180°、pitch ±89°。
- 每个元素按 ID 收集自身确实存在的姿态。隐藏元素仍有几何样本；不存在的元素不生成样本。
- 1 个样本只有该角度有效。共线样本在线段范围内插值；非共线样本使用 Delaunay 三角形覆盖完整 convex hull。
- 覆盖外取最近覆盖位置的冻结结果。曲线用红线、填充/派生线用红色边界参考标示，不进入最终预览。
- 新增发丝只在微侧快照出现时，其它视角均冻结在该快照的已放置位置。没有反推、自动建正面 Key、从中间浮现或写回快照功能。
- 不同样本的对象/描边显隐分别求值，普通墨线与填充的不透明度可随视角过渡。隐藏描边不影响填充的几何边界。
- 显示区间绑定原连续笔画；先统一各快照的笔画方向/闭环接缝，开放区间的 A/B 交换不改变覆盖区域。闭合区间用循环起点和区间长度插值，区分完整一圈与零长度。相同区间 ID 优先对应；同一笔画中重新创建、ID 不同的同类型区间可按覆盖重合对应。真正新增/删除区间才从中点展开/收缩。没有区间轨道意味着整笔显示；转成多区间时从间隙中点打开缺口。
- 层级、填充边界、深度 offset、笔触、雾化保留 Drawing 语义；共同曲线的几何插值后再次满足 SMOOTH 共线约束。
- 不同姿态有不同连接拓扑时，以较近姿态的连接关系求值并提示。不会静默把两个不同节点自动合并；应回绘制间统一连接关系。离散属性（如图层顺序、填充颜色、雾化参数）当前采用较近姿态，未实现动画轨道编辑器。

## 头壳定位

左画布保留只读 HeadSet 曲面/结构线参考，使用与录制角度一致的正交相机。头壳与矢量使用同一观察缩放/平移，单位比例以 HeadFrame 的横向半径为基准，不随 yaw 自动拉伸矢量。工具栏「头壳大小」可独立调节 10%～500%，双击数值可精确输入；只改变参考头壳显示，不改变模型几何或快照。大小全视角共用，随录制保存并支持 Undo/Redo。头壳显示和透明度独立于建模间的模块隐藏。右侧是无头壳、无编辑点的最终预览。

## 数据与旧录制退役

转动时两侧窗口共用一份矢量绘制结果；鼠标事件合并为每个显示帧的最新角度，松手确保提交最终角度。矢量、笔触、显示区间和遮挡始终保持原精度。线条像素笔触使用浏览器原生滤镜。连续转动/平移时雾化填充位图使用较低采样率，停止约 160ms 后自动恢复原始完整精度；它只是临时预览策略，不进入存档。

`project.poseRecording = { version: 1, referenceScale?: number, poses: [...] }`（未设置 referenceScale 时为 1）。每个姿态包含 `id/name/sourceSnapshotId/yaw/pitch/offset/drawing`；drawing 是无背景像素的最近同步内容缓存；sourceSnapshotId 对应的快照是权威来源。更新快照与刷新全部引用在同一个 Undo transaction 内完成。加载/保存旧存档时也重新解析来源，原缓存只有在来源已删除时独立使用。渲染按不可变快照引用复用数据，不逐帧复制。录入不复制参考图，不改变原快照。原快照图像仍由 drawingSnapshots 图片池共享。

根据用户确认，旧 `project.recording` 数据在打开项目、导出及自动保存时清除，不迁移。旧录制曲线/语义点/辅助线、绑定/合并/Smooth 编辑器和背景编辑面板已移除。原 JSON 源文件不会被就地改写；重新保存的文件不含旧录制数据。

后续工作：新增元素缺失姿态反推、手动确认后保存回快照、多视角生产录制校准。这些不在本轮实现。

## 2026-09-25 同步与端点修复

区间两个 marker 的笔触随区间一起插值。各来源先将 width-relative 收尖换算为该来源线宽对应的实际距离，再与 px 收尖插值；不同时保留互相覆盖的 taper 与 taperWidthScale。延伸距离同步插值。新增区间从中点展开时带着自己的两端笔触；整笔到局部区间的过渡保留原有外端笔触，内部缺口的笔触随缺口建立。闭环 0/100% 参数接缝不产生额外笔尖，区间重叠处仍只对并集外端施加笔触。显式零收尖保持零。

验证：新增测试覆盖多姿态引用同步、草稿隔离、一次撤销重做、保留角度/平移/名称、旧存档重解引用、删除来源、混合收尖单位、区间生长及闭环接缝；浏览器验证真实快照更新按钮、录制实时联动、撤销重做及双侧插值收尖。

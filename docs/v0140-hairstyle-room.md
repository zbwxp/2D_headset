# V0.14.18 · 任意视角编辑与可调内收起点（仅本地）

发型生成间有自己的 Drawing 文档、图层、参考图及快照。任意视角下直接编辑二维 Bézier，沿该视角射线投到发网，发网提供深度与转头后的变形。每根发丝仍输出**一段 cubic Bézier**。主绘制间和录制间的数据不受发型编辑影响。用户要求本地迭代，不要主动部署 Sites 或推送 GitHub。

## 当前编辑规则 · V0.14.16

- 正面、侧面、俯仰和背面均可编辑。端点拖动带动相邻 handle；两个 handle 独立移动，另外三个控制点在编辑视角不动。删除了截平面角度工具栏和仅反推角度的编辑行为。
- 整条二维曲线按均匀 Bézier t 取 33 个样本，以**当前编辑视角**向壳体投射；多重交点选距原深度最近的曲面分支。无需共面，也不把 handle 本身吸到壳上。端点仍是可绑定的壳上位置，支持前后侧挂接。
- 最后编辑视角与二维控制柄持久化在 `HairStrandRule.surface`；相机旋转不会覆盖它、重复投射或重抽随机数。在另一个视角开始编辑，才以当前可见曲线为起点建立新的编辑平面。
- 3D 构造样本精确落在曲面上，固定两端拟合一段空间 cubic 供轻量矢量显示。因为拟合只需要补深度，编辑视角的二维 cubic 保持原样；其它视角允许单 cubic 的近似误差。不能宣称任意壳上的精确路径本身就是单段空间 cubic。
- 如果拖动使曲线超出壳在当前视角的投影范围，保留上一次有效结果，并显示具体原因；橙色拖动参考仍显示鼠标目标。改变壳形/随机参数导致已有草稿无法全部投射时，底栏列出未贴合曲线，3D 以红色标记，需调整曲线或发网。有限预览坐标不被当成合法贴面解。
- 打开旧存档不重塑用户原线：旧截面配方只用于还原未编辑的几何；第一次编辑端点/handle 时按当前视角转换。新增线采用新模型，复制保留模型。IDs、图层、绑定、随机范围、显示区间和私有快照继续保留。
- 代码：`surfaceCurve.ts` 做当前视角逐点投影，`inverse.ts` 做直接二维拖动；不再做 handle 的角度优化搜索。静态壳和单线缓存继续生效；32 根发丝基准的 handle CPU 中位数约 0.30–0.43 ms，端点约 0.27–0.28 ms，非浏览器 FPS。见 `artifacts/hair-performance/surface-edit.json`。

本版取代 V0.14.4–7 的固定外侧/中央/内部角色规则。旧名字和当前形状保留，迁移后每根线都按相同参数编辑，不再重新补回已删除的骨架线，也不强制 5° 间隔或高低排序。

## 操作

1. 菜单 → 进入发型生成间。左侧拖动发网旋转，右键/Shift 平移，滚轮缩放；中间 Contour 实时显示，右侧是绘制间共用的图层树。按 **Z** 或点“缩放 Z”后，在左侧 3D 或中间 Contour 按住鼠标向上拖放大、向下拖缩小（斜拖只取上下量）。两视图共享缩放，范围 10%～1200%，鼠标按下位置保持不动。单击放大，Ctrl/Alt+单击缩小；V/A 返回选择，Esc 取消正在进行的缩放并退出工具。输入框输入不触发快捷键，Ctrl/Cmd+Z 保持撤销。导航不修改发丝、不进入 Undo。
2. 点击曲线或图层树中的单根曲线，直接拖动端点与两个 handle；在属性编辑：**发根 XY、发梢 XY、显示区间 A/B**。连续笔画先展开才能选择其中一根。
3. XY 是正视图相对发网中心的归一化位置（沿各轴半径计量），正 Y 向上。参数变化在正面构造，任意视角下看到的都是同一根 3D 发丝；XY 表示基准球的挂接坐标，非新壳的实际投影距离；改壳形会随表面移动。超过基准圆的 XY 径向限幅到前侧可编辑区域。
4. handle 在当前视角自由移动；发网只补深度。旧 `angle`/`bang.mode` 保留为历史配方字段，不再作为编辑约束。
5. 根/梢 XY、显示区间 A/B 各有**基础值 + 随机偏移范围**。展开“随机偏移”，拖两个滑块定义最小/最大偏移；重合时确定，不重合时范围内随机。“固定”归零偏移。例：B 基础 80%，随机 −10%～+10%，实际 B 为 70%～90%。区间结果限在 0%～100%，A/B 交叉取两者之间的线段。
6. “随机所选 / 随机全部”重新抽样。编辑参数使用原样本，转视角、保存和重载不会重新抽样。迁移的已有发丝先固定当前结果，用户自行添加随机范围。锁定曲线不重新随机；与锁定曲线共用的端点也受保护。
7. “＋ 添加发丝”在当前层添加；单选一根时沿用它的参数与随机范围，新线端点独立。图层支持展开、命名、显隐、锁定、排序、复制、删除、Shift 范围选择、Ctrl/Cmd+X/V 剪切粘贴。隐藏/锁定沿用 Drawing 的一次性批处理语义。
8. “绑定端点 / 尖点接笔”后依次点当前层两个端点。重叠端点可通过**选择单根 → 属性 → 选择发根/发梢端点**精确指定。第一端点的位置和随机配置为准。绑定共享位置；尖点额外采用 Drawing 的 CUSP 墨线。工具持续生效，Esc 退出；属性可解除绑定。
9. “保存当前视角快照”将当前投影曲线、显示区间、图层和参考图保存到 `hairstyle.drawingSnapshots`。本版提供保存与数量显示，尚未开放把投影快照反解为发网配方的恢复操作。

## 侧边栏编辑壳形 · V0.14.14

3D 下方“发网壳形 · 南瓜壳”直接调整，无需独立绘制间。这里的南瓜指光滑鼓起、下半部内收的形体，没有新增瓣状凹槽。下缘是实际斜平面与壳的交线：+Z 额头高，−Z 后颈低；显示完整 360° 网壳、底面与下缘。

| 参数 | 意义 | 范围 / 默认 |
|---|---|---|
| 鼓肩宽度 | 最宽横截面相对 X/Z 尺寸的倍率 | 0.65–1.45 / 1.22 |
| 鼓肩高度 | 最宽横截面的高度，相对 Y 半径 | 0–0.60 / 0.35 |
| 顶部圆钝度 | 顶冠由尖圆向饱满过渡 | 25–80% / 64% |
| 下半部内收 | 侧壁向下收拢的程度 | 20–80% / 60% |
| 底面高度 | 斜平面经过中心轴的高度，相对 Y 半径 | −0.60–−0.05 / −0.30 |
| 前后倾斜 | 底面相对水平面的实际角度 | 0–35° / 24° |

高级项“下部过渡”控制鼓肩开始向下弯曲的速度；X/Y/Z 整体尺寸仍单独调。侧面小图随参数更新，前额在左、后颈在右，橙线表示底面。滑块支持双击数值输入；按帧合并，松手提交最后位置，一次拖动一条 Undo。“重置南瓜壳”恢复上表默认；“对照椭球”保留旧椭球作为比较，重开不强制切回。

`HairNet.profile.version=2` 增加 `inset/baseHeight/baseTilt`，原 `width/shoulder/crown/lower` 保留。首次进入旧发型，先提取旧球面的挂接配方，再迁移壳形：保留已有宽度/鼓肩/顶冠/下部设置（限幅到新范围），新增项使用默认。未设置壳形的新发型使用全部新默认。曲线 ID、绑定、随机样本、显示区间、图层和背景都保留；私有历史快照不追溯改写，主 Drawing/Recording 不变。解析仍能读取 v1，编辑器升级一次。

几何是三段纵向 cubic 构成的旋转体按 XYZ 缩放后，再由斜平面裁切。内部下端的闭合段被底面截去。底面世界坐标公式 `y − cy = baseHeight * radiusY + tan(baseTilt) * (z − cz)`，调整 XYZ 不改变倾角。由于下半部内收，不再假定凸壳：截线在指定平面内寻找内部中心，以 33 个径向样本求边界交点，必要时经过真实底面；两端固定拟合一段 cubic。单 cubic 可偏离精确曲面，仍是用户接受的近似拟合，不拆段。

挂接坐标继续使用基准球 XY；南瓜壳把基准球纬度映射到顶冠至当地斜下缘的曲面，保证根梢留在曲面侧壁，不会因抬高底面而悬空或掉到底盘内部。根梢 XY 因此是稳定的挂接坐标，不是投影屏幕距离。射线反推搜所有曲面交点，排除底面以下及不可编辑背侧，保留最靠近原挂接点的分支；不可达目标取最近的可编辑投影。handle 仍反推截面角，不保存额外自由曲线。

沿用静态网壳、单根发丝和截面缓存；转相机不重新求交、不重新随机。32 根合成发丝测试中，最慢 FRONT 模式的 handle / endpoint 几何 CPU 中位数约 1.2 / 1.4 ms（不是浏览器帧时间）。`artifacts/hair-performance/pumpkin.json` 是本版报告。

实现：`domain/hairstyle/{profile,pumpkinSection,geometry,inverse}.ts`；UI `ui/hairstyle/HairProfileEditor.tsx`；验证 `tests/hairstyle-pumpkin.test.ts`，覆盖极限组合、截线贴壳和共面、端点反推、参数保存迁移与缓存。

## 历史：V0.14.9–15 通过 Bézier 反推发网（已由 V0.14.16 取代）

选择单根发丝，中间轮廓显示根、梢端点和两个 handle。直接拖动即可：

- 端点按**当前视角**射线与发网壳求交，更新发根/发梢 XY；有两个合法交点时选离原端点近的一侧，避免深度突然翻面。超出当前可编辑的前球面范围时，贴近其可见投影边界。
- handle 以鼠标位置作为拟合参考，固定两端，拟合 −90°～90° 截面角；也支持“正视展开角”模式。
- 橙色虚线仅在拖动中显示用户提出的自由 Bézier 参考，实线始终是曲面生成结果。角度只有一个形状自由度，无法独立满足任意两个 handle；本功能不把自由 2D 曲线存成另一套权威数据。
- 改动基础位置，保留随机偏移、抽样值及显示区间；绑定端点一起移动，连接到锁定发丝的端点禁止移动。
- 每次拖动一条 Undo，松手提交最后位置，Esc 取消。按动画帧合并拖动更新；相机仍只投影已有 cubic。

V0.14.11 已按用户要求撤回逐根外翘实验，恢复贴壳截线及仅反推角度。加载时丢弃实验字段 `lift`。保留端点/handle 拖动和 3D 面板“回到正脸”（yaw/pitch = 0）。公共壳形在 V0.14.12 加入，并在 V0.14.14 改为上述南瓜壳。

实现：`domain/hairstyle/inverse.ts`；回归：`tests/hairstyle-inverse.test.ts`。

## 背景参考

- 中间工具栏“参考图”插入 PNG/JPG/WebP；也可在属性“从绘制间复制参考图”，深拷贝到发型文档。
- 图层下方展开“参考图”，点击图片名打开属性。提供显隐、锁定、更换、移除、拖动、XY（±10）、旋转、不透明度和 10%～1000% 缩放。
- “参考图状态”提供九个命名位置槽位，保存当前变换；点击已存位置恢复。再次保存覆盖该槽位的变换与名称。
- 参考图是二维叠底，不随球面旋转变形。相机缩放/平移与轮廓一致。
- 参考图转换和编辑可撤销，常规保存 JSON 包含图像及状态。

## 数据与边界

`Hairstyle.version=2`，新可选字段 `strandSet.version=1`：

- `endpoints[]`：稳定 node ID；x/y 的 `{value, random:[min,max]}`；两个持久化 `[0,1]` 样本。
- `curves[]`：稳定 curve ID；根/梢 node ID；固定 angle；start/end 的基础值和随机范围；两个持久化样本。
- 曲线 ID、名字、线宽、显示、锁定、图层、接笔仍在私有 Drawing 文档里。
- Drawing 的共享节点就是共同的球面端点；绑定后的两根线不会因为重新随机而分开。解除绑定会复制当前端点配方，不跳形。
- 删除、复制、剪切粘贴需同步配方图；不要再对 `strandSet` 使用旧的按角色补齐生成器。
- 参考图位于 `hairstyle.drawing.reference`；快照位于 `hairstyle.drawingSnapshots`。禁止写 `project.drawing` 或 `project.poseRecording`。

完整曲面截线只在参数变化时重算。三维每根拟合一条 cubic；相机旋转投影四个控制点。显示区间按正面弧长定位 Bézier t，再换算成当前投影弧长比例，避免转视角时裁切点沿头发滑动。区间是墨线裁切，不改源几何。

主代码：`domain/hairstyle/{model,strandTypes,strands,geometry,drawing}.ts`；UI `ui/hairstyle/`。图层复用 `LayerPanel`，轮廓复用 `PaintScene`；后台测试 `hairstyle-strands.test.ts` 和 `hairstyle.test.ts`。


## V0.14.13 拖动性能

新壳形上线后，最慢路径是正视展开角模式：每次 handle 反推几十个截面，每个截面密集求交；保存正面和视图又各生成一遍全部发丝，WebGL 连网壳缓冲也全部销毁重建。

现在固定发网的 mesh/wire 缓存；发丝按端点、角度、模式复用，只有被改动的发丝及共享端点所连发丝需要求交。同一配方的保存正面和视图共用一次生成。截面搜索缓存按发网隔离并限制容量，旧式生成器修改的 inkRange 不泄漏进缓存。新壳截线采样 65→33，handle 局部搜索 24→12 次；曲面求交内循环改为标量运算。拖动与松手使用同一算法，不在松手时换一个精确解。每根仍是一段 cubic，几何身份、随机样本、显示区间不变。

3D 网壳不因拖动发丝而重新上传，发丝 buffer 仅更新有变化的坐标，每次 React 提交只绘制一次。橙色参考线也与模型一起按帧合并。独立发型/绘制编辑不会再触发无关的 HeadSet 连续性键计算，返回建模或录制仍正常求解。

本机合成 4/32 根发丝基准（35° yaw / 15° pitch，25 步）：32 根最慢 FRONT handle 的几何 CPU 中位数约 464→0.7 ms，单端点约 433→1.0 ms。数据不包含 React、布局、SVG 栅格化和 GPU，不能换算成浏览器 FPS。42 组原高精度截线对照最大拟合偏差 0.0000394R。报告与复现命令见 `artifacts/hair-performance/README.md`。

## 发网叠加 · V0.14.17

发型轮廓工具条的“叠加发网”默认开启，不透明度默认 45%，可调 0–100%。渲染顺序是参考图 → 半透明网壳/经纬线/斜底面 → 发丝及编辑控制柄。它与轮廓共用相机、缩放、平移；修改壳形和尺寸实时更新。叠加层不接收鼠标事件，不进入图层或快照；开关和透明度是会话视图偏好。使用现有网格的 SVG 投影缓存，不增设 WebGL 画布，也不重复计算发丝。

## 内收起始高度 · V0.14.18

“发网壳形”在“下半部内收”上方增加“内收起始高度”，范围 −0.50～0.85 R（沿 Y 半径计量，中心为 0，顶部为 1）。数值增大时，向内收拢的影响从更高处开始；原“下半部内收”继续控制幅度，“鼓肩高度”定义未内收的基础外形。侧面小图的绿色虚线标出起始高度。真实 3D 网壳、底面边缘、轮廓叠加和发丝共用更新后的曲面。

新增可选字段 `profile.insetStart`。旧存档缺省时仍取原 `shoulder`，完整保留旧壳形；首次改参数时固化该值，让两个高度可以独立编辑。新建默认 0.35 R。修改可撤销、可保存；未影响原始发丝 ID、绑定和显示区间。

几何上，将已有内收的径向位移重新分布到指定起点以下，上方圆冠不受该内收影响；起点使用零斜率过渡，并在内部底部闭合段保留原值及一阶导数。沿用预计算半径表，查询成本与此前一致。

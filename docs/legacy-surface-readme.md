# Contour — 语义头部曲面工作室

一个可本地运行的 V0 头部曲面编辑器。所有形体修改来自二维视图中的外轮廓和语义线，多个视角共同约束同一张固定拓扑曲面。三维视图用于检查。

## 运行

需要 Node.js 22.12+（本项目在 Node 24 下验证）。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173/`。

```bash
npm run build       # TypeScript 检查与生产构建，输出 dist/
npm run preview     # 预览生产构建
npm test            # 几何、曲线、序列化和真实求解测试
npm run test:e2e     # 浏览器交互与截图回归
```

macOS 测试默认使用已安装的 Google Chrome。其他平台先执行 `npx playwright install chromium`。截图基线随平台命名；首次在其他平台运行，检查画面后执行 `npm run test:e2e -- --update-snapshots` 创建该平台基线。不要用更新基线来跳过未调查的视觉回归。

## 最小操作流程

1. 选择「正面」和「下颌」，拖动控制点，调整下颌宽度和高度。
2. 等待求解完成，点击视角栏右侧的锁按钮保护正面。
3. 切到「侧面」，选择「颅顶」调整后脑，或选择「下巴」调整前伸。
4. 在三维区域拖动旋转、右键平移、滚轮缩放。切换线框、语义线、法线或曲率近似检查。
5. 查看各视图的 RMS 误差；点击「精细求解」。不兼容的目标会明确提示冲突。
6. 「保存项目」下载 JSON；「载入项目」恢复 JSON；「导出 OBJ」输出带法线的网格。

二维滚轮缩放；Shift + 拖动平移；双击曲线或点击加号添加控制点；选中点后 Delete / Backspace 删除。控制点可 Tab 聚焦，以方向键微调，Shift + 方向键增大步长。⌘ / Ctrl + Z 撤销，Shift + ⌘ / Ctrl + Z 重做，⌘ / Ctrl + S 保存。

新建、载入、曲线编辑、锁定、强度和设置修改可撤销，保留最近 100 次状态（同一次拖动计为一步，刷新后历史重置）。新建无需确认，可直接撤销恢复。每次完成求解后自动保存到当前浏览器的 localStorage；这是当前设备的单项目恢复，不是云同步。需要保留多个项目时请分别下载 JSON。文件解析失败不会替换当前项目。

## 参考照片

二维画布右上角点击「载入参考照片」，支持 JPG / PNG / WebP（原图最大 20 MB）。每个视角独立保存一张参考图。图片在本地缩小到适合描摹的分辨率并压缩，嵌入项目 JSON，不会上传。

点击「参考图」可调整透明度、缩放、水平/垂直位置和旋转。选择「平移图片」后，直接拖动画布背景移动照片，点击「完成定位」回到曲线编辑。「锁定」保护图片位置、大小、旋转和透明度；解除锁定后才能继续调整或移除。显示/隐藏不影响锁定。图片变换与二维画布缩放独立，参考图本身不参与曲面求解。

参考图导入、变换、锁定和移除均可撤销；Ctrl / ⌘Z 可在滑块聚焦时使用。历史最多 100 步，按钮提示显示当前剩余步数。编辑历史保存在当前会话；刷新恢复项目及图片，但不恢复撤销栈。

## 已实现的 V0

- React / TypeScript / Vite / Three.js / Zustand，中文编辑器，桌面双视图区与窄屏纵向布局。
- 六个正交视角：正面、左/右 45°、侧面、俯/仰 45°。
- 994 顶点 / 1,984 三角面的闭合椭球求解网格；3,970 顶点 / 7,936 三角面的细分检查网格。
- 八条语义曲线：颅顶、眉弓、脸颊、口鼻区域、下颌、下巴、颈部连接、正中线。
- 外轮廓提取、曲线点拖动/添加/删除、实时投影对照与偏差线。
- Web Worker 中的稀疏加权最小二乘、Laplacian 保形光顺、锚点、中心约束、精确左右对称降维、时间稳定项。
- weak / strong / locked / guide、逐约束启用与整视角锁定；错误和冲突提示。
- Three.js 粘土、法线、曲率近似、线框、语义线、固定视角缩略图；三维没有形体编辑入口。
- JSON 保存/加载、本机自动保存、撤销/重做、OBJ 导出。
- 单元/集成测试、Playwright 操作测试、六种截图基线、视觉 QA 记录和可选 VLM 接口文件。

## 边界

V0 使用闭合 polyline，而非 Bezier。外轮廓默认按语义层两端和层间中点提供约 28 个定位点，语义曲线提供两端和中间点；密集采样由可见控制点重建，不再拥有独立的局部形变。正面、侧面和水平 45° 的语义线按可见点分段线性插值；三点共线时整条环线的投影共线。俯仰视角保留由相机投影产生的基底弧度。外轮廓使用穿过定位点的闭合插值曲线。旧项目保留已有控制点、照片和网格，并自动修正旧语义目标的隐藏波峰；点击精细求解可同步曲面。语义对应是固定顶点采样，轮廓使用面朝向变化的边界近似。大幅凹陷、轮廓拓扑变化、互相矛盾的视角可能无法同时拟合；锁定是更高优先级，不能把几何上不可能的目标变为可满足。误差会在界面显示。一次更新最多移动 0.12 单位，大改形状可多次精细求解。

曲率显示是非归一化离散 Laplacian 位移的可视近似，不是用于精密分析的曲率。细分增加检查网格密度，不改变导出的固定求解拓扑。没有五官、耳朵、头发、雕刻笔刷、拓扑编辑、绑定、图像重建或云服务。

数值验收基于文档中的标准场景，不保证任意极端约束或所有硬件都满足性能目标。具体模型、测量单位与限制见 [求解说明](docs/solver-notes.md)，验证结果见 [QA 记录](docs/qa/report.md)。

## 代码结构

- `src/domain/geometry/`：向量、网格、法线、正交投影、轮廓提取、细分。
- `src/domain/curves/`：曲线参数化、插值、最近点。
- `src/domain/semantics/`：固定拓扑上的语义采样。
- `src/domain/project/`：数据类型、默认项目、严格加载校验、序列化与 OBJ。
- `src/domain/solver/`：稀疏系统、预条件共轭梯度、能量和诊断。
- `src/workers/`：可替换求解器的 Worker 入口。
- `src/app/`：状态、历史、调度、持久化和界面框架。
- `src/ui/`：二维编辑与只读三维检查。
- `src/tests/`、`tests/e2e/`：数值、交互、截图回归。

可选浏览器 WebMCP 接口仅提供读取诊断与切换视角，使用同一状态操作；不支持该实验性 API 的浏览器会自动跳过。没有调用外部 AI 服务或上传项目。外部字体不可用时使用系统字体回退。

面部正中线是从头顶到下巴的固定前侧经线，以金色显示在二维、三维和缩略图中。它跟随曲面变形和相机投影，左右 45° 时自然偏向相应一侧；不绕后脑闭合，不单独提供形变控制点，也不参与约束求解。关闭其他语义线时仍显示；三维被遮挡部分使用较淡虚线辅助识别。

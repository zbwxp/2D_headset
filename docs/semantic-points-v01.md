# V0.1 Semantic Point Editor

本版本只编辑真正的三维语义点。没有曲线、语义环、头部网格、曲面求解、fairing 或自动拟合。旧 surface 模块留在仓库供历史参考，应用不再调用；旧浏览器验收移至 `tests/legacy-surface-e2e`。

## 数据与文件

- `src/domain/landmarks/model.ts`：SemanticLandmark、ViewLock、LandmarkProject 及硬约束求交。
- `src/domain/landmarks/presets.ts`：6 个中心线点、7 对镜像点，共 20 个中文预设，创建时生成稳定 UUID。
- `src/domain/landmarks/persistence.ts`：校验 UUID、镜像关系、相机、参考图与锁定坐标一致性；拒绝不一致项目。
- `src/app/store.ts`：`project.landmarks` 唯一几何状态，选择、编辑、全视图锁、100 步撤销和保存。
- `src/app/App.tsx` / `styles.css`：保留布局和配色，替换曲线列表及曲面工具为语义点操作。
- `src/ui/edit2d/EditView.tsx`：共享世界坐标投影、拖动、允许轨迹、键盘微调和预览。
- `src/ui/inspect3d/InspectView.tsx`：保留 Three.js 相机和 OrbitControls，仅渲染点、坐标轴和背景网格。
- `src/ui/edit2d/ReferenceControls.tsx`：原样保留。
- `src/domain/geometry/core.ts`：复用正交 basis/project，放宽函数类型以独立于旧 View 全局锁字段。
- `src/app/webmcp.ts`：停用旧曲面操作入口。
- `src/tests/landmarks.test.ts`、`tests/e2e/landmarks.spec.ts`：V0.1 验收。

新存储键为 `contour.landmarks.v01`。旧 `contour.project.v1` 不覆盖、不删除。首次启动可继承旧自动保存里的参考图和画布设置，但旧曲面不转换为语义点，所有新点都使用预设且无锁。旧 JSON 不支持直接导入本版本。

## 锁与自由度

View Lock 仍由视图统一开关，但每对镜像点只有一份独立变量和一份 driver observation。当前选中的 LEFT/RIGHT 是 driver；另一侧为 dependent follower，位置始终镜像 driver。follower 不贡献投影约束，它在锁定视图中的屏幕投影允许改变。

`landmark.viewLocks[viewId]` 保存 driver 锁定时的相机成像平面单位基 right/up，以及两个世界投影值 `dot(position,right)`、`dot(position,up)`。follower 的 viewLocks 为空。切换到另一侧时，用原锁定相机基和新 driver 的当前位置重新确定锚点，移交同一组显式视图锁；不新增视图、不移动点、不额外消耗自由度。切换相机只投影已有可行空间。

每个 driver 的可移动增量满足：

- 中心线点：delta.x = 0。
- 每个显式 View Lock：dot(delta,right) = dot(delta,up) = 0。
- Symmetry 只用于计算 follower.position = Mirror(driver.position)，不添加矩阵行。

普通点 0 锁可通过当前相机平面编辑；1 个独立锁保留沿锁定相机方向的世界空间直线；2 个独立锁为 0DOF。中心线仍与 x=0 求交。

用正交化求这些约束法向量共同零空间，维数就是界面显示的剩余 3D DOF。平行重复锁不重复扣除维数。中心线点与侧视锁相交可以直接为 0DOF。

鼠标位移投影到可行空间在当前视图中的像，求最小长度的世界位移。这里的投影仅限制鼠标意图，不放松任何已有硬约束。没有自己或伙伴的视图锁时，还临时加入当前相机深度不变约束；中心线点也必须与这个拖动平面求交。界面 DOF 显示持久约束剩余的三维自由度，当前视图实际可拖动维数可能更少。无锁普通点因此保持当前相机深度；1DOF 显示允许轨迹；0DOF 禁止移动。轨迹沿当前视线时没有可见移动，需切换视图。一次编辑仅改变该点及其镜像伙伴。

锁只由用户切换。View checkbox 显示整个视图的统一锁状态。上方“显式视图锁”栏展示所有锁来源，可不切换视角直接解锁。所有计算使用双精度浮点；数据校验容差为 1e-8 世界单位。

## 启动

在项目目录运行 `npm run dev -- --port 5173`，访问 http://127.0.0.1:5173/。

## 手工验收

1. 载入正脸 PNG，选择左外眼角点，在正面拖动；切换 45°、侧面，检查同一点投影及 3D 高亮点。其镜像点同步，其他点不变。
2. 正面手动勾选 Lock，切侧面；显示金色允许轨迹，任意拖动都沿轨迹，正面投影不变。
3. 侧面也 Lock，切 45°；显示 0DOF，无法移动，提示 Unlock。
4. 点击“解锁正面全部点”；只剩侧视锁。切换其他点，确认视图锁状态相同。中心线点有额外 x=0 硬约束，侧视锁下仍为 0DOF，这是同一求交规则的结果。
5. 选择鼻尖点：始终 x=0；侧视 Lock 后立即 0DOF。
6. 在正面锁定时切换左右 45°，拖动成对点；检查左 x = −右 x，y、z 相同，且所有点正面投影不变。两点同向屏幕横移可能来自共同的深度移动，不等于破坏三维镜像。
7. 修改图片透明度、位置、缩放、旋转，锁参考图；平移缩放画布、调整窗口大小，所有点的 View Lock 保持不变。
8. 连续编辑超过三步，用 Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 重做；保存 JSON、刷新或重新打开，坐标与锁保持。

## 当前限制

- 仅 V0.1；没有复制、重命名语义点、曲线或曲面功能。
- 对称固定开启；左右按角色自身方向。完全重合的投影可用侧栏选择目标点。
- 3D 是只读检查，选点在二维画布或侧栏完成。
- 历史最多 100 步且只在当前会话内有效，刷新不恢复历史。
- 参考图仍沿用现有压缩机制与浏览器存储容量限制。
- 如果所有可行运动恰好朝向当前相机深度，当前视图看不到可拖动轨迹，切换观察角度即可。

## 验证结果

构建、38 项单元测试、5 组浏览器测试通过。新增 driver 回归覆盖：

- 右外眼角仅锁右 45° → 纯俯视中可沿斜线拖动，左点镜像跟随。
- 右 30° → 正面，以及右 15° → 侧面保留 1DOF。
- 同锁定视图投影不可移动，但三维自由度仍为 1。
- 第二个独立显式锁后为 0DOF。
- driver 交换不跳点，保存加载保留角色归属和锁，撤销/重做恢复位置。

## 旧数据与指示线

旧文件如果给左右点都存了投影观察，会合并为一份 driver 观察，默认选右点为 driver；随后选中左点可正常交换角色。迁移不改变几何坐标。新版文件只有 driver 保存锁快照，follower 不会在加载时被自动加锁。

二维、缩略图和 3D 以细虚线连接已有中心线点，仅为只读参考，不创建 Curve 几何。纯点击不修改坐标或撤销历史；选择镜像另一侧会移交锁归属并在当前位置重新确定锚点。拖动保留抓取偏移以避免跳点。

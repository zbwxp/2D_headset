# V0.5.5.2 — Contour Chains

Rollback baseline: 4c3308e, branch codex/checkpoint-before-v0.5.5.2.
Working branch: codex/v0.5.5.2-contour-chains.

Tangent edges are now walked into topology-connected chains, stopping at branches.
Each segment carries the incident faces of its endpoint vertices. The depth raster
stores the winning triangle ID. Visibility retains normal depth rejection except
for bounded uncertain runs: both ends must be visible, chain length at most 4
mask pixels, occluder a local incident face, depth disagreement at most 8 times
the existing scene-relative epsilon (8e-5 of scene scale). Repair follows existing
chain samples, never a screen-space chord between disconnected endpoints.

Other surfaces, nonlocal self-occlusion, long gaps, missing candidates, and chain
endpoints are not bridged. Open boundary handling is unchanged. No source or
persistence changes; main GPU scene and mask outer contour unchanged.

Validation: 21 contour unit tests, 4 Playwright tests, build passed. Tests include
local uncertain gaps, clear/foreign occlusion, long gaps, endpoint rejection and
topological chaining. Existing actual-head screenshot still shows a small chin
fragment: this conservative change is not claimed to fix missing candidates or
all grazing-angle artifacts. User evaluation at the reported camera orientation
is still needed; no blanket visual completion claim.

To roll back this experiment after saving any newer code changes, switch to
codex/checkpoint-before-v0.5.5.2. Model JSON is unaffected.

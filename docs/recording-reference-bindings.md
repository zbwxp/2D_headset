# 录制参考图的视角绑定

录制模式使用左侧「参考 / 辅助线」入口。右侧共用图层面板不再显示重复的「参考图 +」区域；绘制模式保留原有参考图入口。

载入参考图，调整位置、缩放、旋转与透明度，再点「绑定当前视角」。绑定使用当前录制的精确 X / Y 角度，不要求该角度已经有真实快照，也不会建立视角、来源、几何或关键帧。

绑定后仍可临时移动或调整图片。离开并回到同一精确角度时，恢复上次绑定的四项值。想保存新的对齐方式，点击「更新当前视角绑定」。未绑定角度保持当前参考图行为；不会寻找最近绑定或插值。锁定图片时也可以绑定，其锁定和显示状态保持不变。

绑定按录制和图片身份独立保存。替换或移除图片会清空当前图片的绑定；即使重新载入同一个文件，也视为新图片。Undo / Redo 可以恢复先前的图片、临时变换和绑定；一次拖动只占一条历史，角度切换的自动恢复不新增历史。

参考图和绑定存在本机工作区存储中，刷新后可恢复；工程 JSON 不包含它们。Undo / Redo 栈仍仅保留当前会话。旧版没有绑定的本机参考图继续保持原对齐方式。

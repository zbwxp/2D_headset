# 0–90° 向右转头工作稿

这个例稿使用一份134段源稿、13个Bézier Warp变形器和真实参数关键形。不是在正面与侧面图片之间淡化。X=0为正面，+X向画面右转，X=90为右侧面；本例只完成正向水平转头，负X与仰俯Y锚点仍为中性姿态。

原始21视图参考表的14号为正面、8号为侧面；本例将8号水平镜像作为向右侧稿的基准。格子编号不代表角度。

## 打开与继续编辑

在“载入示例”菜单中选择“0–90° 转头工作稿”会新增独立的正面参考、侧面参考和转头源稿/录制，不覆盖现有画稿。未保存源稿先另存，整个载入可一次撤销。载入后切换到录制模式，拖动Angle X可查看0–90°。

- 源线、真实端点、图层、白填充和显示区间的基本结构在绘制模式编辑
- 录制模式只修改网格、角度关键形和区间覆盖的姿态覆写
- 已有关键形为0、15、30、45、48、50、55、60、90°；48/50°负责轮廓交接，55°负责远侧部件遮挡
- 原始正面参考和90°侧参考作为单独画稿保留，也可在“参考 / 辅助线”中只读叠放或并排
- 网格修改后应保存当前关键形，再移动参数；正面镜像编辑不自动应用于非对称转头姿态

## 轮廓与材料交接

后下颌副本与原段在本例源稿中具有相同控制点，并绑定到同一个完整变形链。源稿中的Q接点经过显式分段，使用真实POSITION端点联动；下巴继续使用既有跨层ARC末端笔触。复制不会创建永久控制柄复制关系，今后编辑源稿时需要共同维护这两组控制点。

0–15°先让新路径覆盖共形下颌，15–30°才撤回旧路径的相同部分。45–48°从真实Q连续展开鼻唇线，旧上颌保持可见；48°新轮廓已连续覆盖后，48–50°才撤回旧上颌。46–49°仍可见短暂的旧颊支线或窄双线，这是首版可继续精调的美术限制，不是断线或曲线拓扑切换。

远眼、眉、耳使用温和的几何调整、区间覆盖和原有白填充遮挡。没有用全层离散显隐替代连续过渡。源墨线的内部闭合边仍通过HIDE隐藏，白填充继续闭合。

## 可复现构建

在仓库根目录运行，选择一个不存在的新输出目录：

```sh
node scripts/authoring/build-yaw-example.mjs artifacts/yaw-reproduction
```

依赖现有npm开发环境，以及Python的NumPy、SciPy。该命令依次：

1. 从仓库保存的镜像正面和90°侧参考建立新的独立源稿
2. 通过公开源稿API创建侧部件、复制后颌，并显式分段/联动Q
3. 通过公开录制API创建并绑定13个变形器
4. 用明确的源/目标cubic对应和精确位置约束拟合90°与30°修正网格
5. 通过公开录制API写入全部关键形，验证源稿与参考画稿未被录制修改

所有批次配方、拟合输入/结果、材料定位和诊断写入指定输出目录。新运行会生成新的对象ID和时间戳；不要用整个JSON的字节相等代替几何/渲染复现检查。当前完整新目录重跑在0/15/30/45/60/75/90°的画面内容逐像素与最终例稿相同。

拟合器不改变生产容差，不拆分输出cubic，也不将连续场的目标误差当作单cubic近似误差。每条源段仍只有一条输出cubic。端点与共享场请求冲突会单独报告；任意独立网格编辑不保证仍低于1px误差。

## 生产渲染与检查

静帧、联系表和动画使用实际PaintScene，包括白填充、层级、显示区间和雾化效果。离线工具通过真实Canvas实现运行同一个SVG渲染器。它不替代浏览器交互验收。

需要可用的`@napi-rs/canvas`模块。可通过`CONTOUR_CANVAS_MODULE`指定独立工具安装位置，不必添加到应用运行依赖。

```sh
CONTOUR_CANVAS_MODULE=/absolute/path/to/node_modules/@napi-rs/canvas \
node scripts/authoring/render-turn-frames.mjs \
  artifacts/yaw-reproduction/yaw-final-rig-project.json artifacts/yaw-frames

CONTOUR_CANVAS_MODULE=/absolute/path/to/node_modules/@napi-rs/canvas \
node scripts/authoring/render-yaw-animation.mjs \
  artifacts/yaw-reproduction/yaw-final-rig-project.json artifacts/yaw-animation
```

动画工具额外需要ffmpeg，逐1°渲染0–90并反向播放，输出181帧、800×800、24fps的MP4，同时保存91个实际SVG和每角度诊断。它不会通过图像交叉淡化生成中间帧。

当前冻结例稿的91个整数角度均无route/区间运输/拟合警告，最大拟合误差约0.899 nominal px。另有1801个0.05°姿态有效性检查、101个密集45–50°覆盖检查和259个小网格扰动连续性检查；较大的矛盾场请求仍诚实产生拟合或端点约束误差。独立浏览器文件导入及最终交互验收尚待完成。

仓库最终验证：低并发完整运行共1522测试，1513通过、7失败、2跳过。7项失败在修改前的02e97da隔离基线逐项复现，涉及缺失的旧桌面眼部文件和已退役3D流程的断言，未纳入本次改动。首次全并发中的两项runner错误在低并发重跑通过；ARC旧负例已更新为真正坍塌的几何。生产build与8项Python拟合器检查通过。这里没有将已知失败包装成“全套通过”。

# V0.3.9 — Patch Preparation

## 范围与归档

当前 active geometry pipeline 为 `SemanticLandmark → Planar Source Curve`。
V0.3.8 完整保留在 `v0.3.8-surface-smooth-node` / `0b2fe3a`；本轮分支为 `v0.3.9-patch-prep`。

删除 `src/domain/surfaceSmooth/`、`src/domain/junctions/` 与 `src/ui/junctions/`。从 store、session、Landmark model/presets/persistence/management、Curve management、App、EditView、CurveLayer、InspectView、CSS 中移除专属状态、Inspector、extent、参与/排除、切平面、fairing、hover/debug 和 resolved picking。也移除用于打开旧 Inspector 的特殊双击时间检测。

2D 与缩略图直接生成 source cubic SVG；3D 直接离散采样同一 source cubic。Plane/handle/body 编辑即时决定显示几何。没有隐藏 evaluated Smooth geometry。

通用 Bézier 求值、导数、曲率向量计算、de Casteljau split、bounds、误差控制 flatten 保存在 `src/domain/geometry/bezier.ts`，并保留通用 arc-length LUT。原 Curve geometry 中的 nearest-parameter、Plane、minimal-rotation endpoint transport，以及 Vec3/矩阵、View Lock、对称数学保持原实现。

新版本 `landmarks-0.3.9`。Loader 识别旧版本并只提取 source 字段：旧 `smoothJunctions`、`surfaceSmoothNodes`、`surfaceSmoothDefaults` 无论内容为何均忽略，不参与求值，新 Save 不输出这些字段。

自动保存使用 `contour.landmarks.v039`，可回读 v038 等旧键；不删除旧浏览器存档。

颊峰拓扑是本次对当前 Cage 的编辑，不是给任意旧项目自动加点的 migration。当前用户标签页已通过普通 Duplicate、点拖动、Create Curve、Rename 操作完成；参考图没有调整。

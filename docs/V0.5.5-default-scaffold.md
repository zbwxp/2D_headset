# V0.5.5 Default Head Scaffold

Default scaffold is additive on load and enabled on new/reset. It owns 5 Curve records (3 main logical rings and a side mirror pair) and 16 derived Landmark records. System ownership prevents deletion, independently of edit locks.

Main rings remain in their principal planes through HeadFrame origin. Side rings expose synchronized normalized offset, initially 0.75. A copied horizontal Composite Ring is one logical loop with two shared endpoint UUIDs and offset-only editing; other copies are ordinary editable Sections.

Intersection positions and multi-host membership are derived analytically. Span authoring uses exact host parameters; system points remain ordinary endpoint references for dependent curves. Apex is evaluated on the final Helmet at height 0.85; convexity defaults to 0.8. Existing optional Apex XYZ offset is applied after this derived base position.

Helmet is one continuous field evaluated on the ellipsoid, with a separate domain mask. The field has zero displacement and derivative change at the side ring. A small normalized 0.035 circular transition rounds only the open-rim mask junction, following visible contour inspection. No surface fairing solver is added. Rendering and silhouette consume the same derived surface; no mesh is persisted. Arbitrary point hosting on Helmet remains deferred.

Scaffold source stores version, sidePosition, convexity, apexHeight and visible. Fixed IDs/roles identify system geometry. User ring copies use ordinary IDs. Composite copies additionally store their shared endpoint references; endpoint coordinates are ON_CURVE-derived, never stored world samples. Save/load and existing history preserve these source records.

Validation covers analytic memberships, exact mirrored spans, Apex-on-field, derivative continuity, mesh symmetry, copy/delete cascades, persistence, downstream free curves and patch authoring. Browser regressions include scaffold interaction, numeric controls and 3D reference backgrounds. Existing legacy solver migration can exceed its five-second test timeout under concurrent test/build load; numerical tolerances were not changed.

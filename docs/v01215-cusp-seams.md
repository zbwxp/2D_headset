# V0.12.15 · Cusp Seam Fix

修复变宽笔触、显示区间笔触在尖点根部出现白缝与缺口的问题。

原轮廓在接点处跨两侧采样点计算平均方向，随后将尖角作为另一块图形叠上去；平均方向得到的笔触边缘与尖角使用的两侧单边法线不一致，导致根部缺肉。

现在尖点保留两侧各自的末端切向与局部线宽，将尖端直接接入同一条墨线外轮廓。变宽笔触不再额外叠画尖角。等宽 SVG stroke 路径保持现有处理。

保留 5 × 两侧平均完整线宽的尖点延伸上限，不修改源曲线、控制柄、填充边界或连接关系。

使用既有刘海存档的精简点线数据，加显示区间收尖复现。覆盖根部非零环绕数、镜像、反向遍历、闭环跨起点区间，以及浏览器实际墨线像素检查。

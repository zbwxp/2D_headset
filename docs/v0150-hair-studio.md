# V0.15.0 — 发型绘制与发网烘焙（本地）

发型间新增独立的完整二维工作稿，直接复用 DrawingRoom 的工具、图层、属性、快照、背景与编辑行为。不是另复制一套编辑器；`HairStudioProvider` 把编辑动作路由到 `project.hairstyle.studio`。主 Drawing、主快照与 Recording 都保持独立。原来的程序化发丝仍通过“参数发丝”进入，配方和图层保留。

## 操作

1. 进入发型生成间，点“载入绘制间快照”，选择正面快照并载入独立副本。也可载入绘制间当前工作稿。
2. 利用完整图层面板隐藏其他内容，只留下要烘焙的面发及白色填充。线条隐藏不等于填充隐藏，沿用 Drawing 的规则。上方烘焙操作针对当前可见内容，而不是当前选择。
3. 二维画布始终显示正面源稿。叠加半透明发网，通过画布上方“发网定位”的 X/Y 滑条平移，通过左栏 XYZ 尺寸、南瓜壳参数对齐。背景图通过参考图控件独立移动；背景图与辅助标记不参与烘焙。X/Y 支持双击数值输入及撤销，修改的是真实发网位置，烘焙会使用这个位置。参数发丝模式也提供同一定位栏，贴壳发丝随发网移动。
4. 点“烘焙可见内容到发网”。超出前部发网覆盖的内容会提示，不会静默丢掉；调整覆盖范围后重试。
5. V0.15.2 起，烘焙直接显示在原画布和左侧发网上，不再切换到独立预览窗口。背景、图层、工具栏、画布缩放和平移保持不变。左侧拖动发网或调整 yaw/pitch，两处贴壳结果同步转动；原画布继续支持 Z 缩放、抓手和平移参考图。画布上方的“平移参考图”会选中参考图并展开其属性；锁定时按钮明确显示“解锁并平移参考图”。图片缩放仍在右侧属性里。参考图修改不改变烘焙缓存，不需要重新烘焙。
6. 点“二维编辑 · 正面”或选择绘图工具/源线条，会在同一界面切回正面源稿编辑；改完再次烘焙。点“烘焙贴壳”可重新查看已有结果。源稿或发网改变后会提示预览仍为上次烘焙；不会把旧结果冒充新结果。
7. 存档随“保存 JSON”及本地自动保存保留。导入、编辑与烘焙可撤销/重做。导入不会删除发型间已保存的私有快照。

## 数据与显示策略

- `hairstyle.studio.drawing`：完整 DrawingDocument；不经过程序化发丝的 `editHairDrawing` 约束。
- `hairstyle.studio.drawingSnapshots`：发型工作稿自己的二维检查点，来源于复用的快照工具栏。此栏不直接修改主绘制间快照。
- `hairstyle.studio.baked`：冻结的矢量源稿（去掉背景）和发网配方。记录填充显示开关的结果；原始工作稿不被修改。
- `hairstyle.drawing / strandSet`：保留原来的参数发丝系统，和 studio 分开；公共发网 net 共用。
- 烘焙按正面 +Z 投射。曲面使用现有南瓜壳/椭球；固定前部 UV，转相机不改源线、不重算显示区间。
- **本版预览是矢量源稿 + GPU 贴图缓存，不是每个视角重新生成 Bézier 曲线。** 使用与绘制间相同的 PaintScene 绘制黑白填充、透明挖空、显示区间、笔触、墨边和雾化填充，再生成长边 3072px 的透明显示缓存。原始矢量及关系仍完整保存在文档中。
- 缓存最多两个版本，不随每次历史记录无限积累；视角转动只更新相机。网格缓冲、材质和 WebGL 资源在切换时释放。全壳深度遮挡 + 前面材质避免正面头发从后脑透出。
- 本次只完成面发的可转动预览，不自动生成侧发/后发，不导出各角度独立矢量快照，不把它接入 Recording。后续如需可编辑的各角度曲线，要另做曲线在壳上的采样投影和拟合，不能把这个贴图缓存称作矢量输出。

## 验证

`npm run test:release`：344 通过、1 个性能基准按原配置跳过。新增测试覆盖独立副本、编辑器路由与 Undo、隐藏边界的填充、填充预览开关、笔触延伸范围、南瓜曲面与 UV、保存加载及错误数据拒绝。

本地 Chrome 使用现有“正面”快照，只显示中央/左/右刘海：覆盖检查、发网对齐、带白底烘焙、正面/45°/背面和透明棋盘格检查。原绘制间数据隔离由测试验证。

### V0.15.2 界面修正

DrawingRoom 持续挂载，通过 artworkPreview 只替换画布中的线稿显示。背景 SVG、图层、属性、工具与视口状态复用原组件。烘焙纹理不与源稿叠画，避免转角后仍显示静止的正面线；选择编辑工具会回到可编辑的二维源稿。背景移动仍使用原编辑事务和撤销机制。

### V0.15.3 俯仰轴修正

发网 pitch 按头部自身左右轴俯仰，再组合 yaw；不再把 orbit 相机的抬高/降低当作点头。yaw 为 ±90° 时依然沿头部前后方向抬头/低头。3D 构造、烘焙纹理、画布发网和参数发丝的投影/逆投影共用同一基底；正面及 pitch=0 的视角保持原样。转动仍只改相机/投影，不重新烘焙。

旧参数发丝 surface.version=1 保存的手柄和深度继续按原编辑坐标系还原，以免加载后变形；新编辑使用 version=2。端点或手柄编辑会从当前 3D 形状重投影，按新的视角坐标存储。缓存键包含此版本，支持两种数据保存加载。

验证：发型单元测试 65 通过、1 个性能基准按原配置跳过；涵盖左右侧面俯仰、±90° 俯仰基底、Three 相机与二维坐标一致、旧斜视角发丝的几何快照和 V2 重编辑。

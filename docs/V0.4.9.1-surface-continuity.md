# V0.4.9.1 — Automatic Patch-Pair Surface Continuity

## 使用方式

选中结构线，在 Curve Inspector 的 **Surface Continuity** 中点击一条边界行：

- 1 个附着面：Natural。
- 2 个附着面：默认 Auto；用 Crease 恢复独立自然曲面，Restore Auto 恢复自动配对。
- 3 个或更多面：该边界不自动配对。选择两个面后 Set Pair；可 Change Pair / Clear Pair。
- 悬停行时，Main 2D 与 3D 同时高亮该实际区间。
- 镜像侧关系同步；下拉菜单区分左右。

同一宿主上的不同区间单独显示，按起始弧长比例排序。完整曲线不被隐式拆分，部分重叠区间不建立关系。3+ 附着只影响这一条边界，不取消其他边界的配对。

## 数据与迁移

项目版本 `landmarks-0.4.9.1`，新增：

```ts
surfaceContinuity?: {
  overrides: Record<BoundaryKey,
    | {mode: 'crease'}
    | {mode: 'manual'; patchIds: [string, string]}>
}
```

Auto 从精确边界拓扑派生，不保存。BoundaryKey 复用 V0.4.9 的 host + unordered anchor UUID 身份；完整宿主的旧 key 保留。不会按空间距离配对。

旧 global enabled、strength、band 和中间 influence 不再进入新求解。明确的 canonical Curve influence=0 迁移成该宿主现存 exact boundaries 的 Crease，并同步镜像。旧 enabled=false 不阻止 Auto。

删除 Manual 成员后清除无效关系，再按剩余拓扑派生；几何退化不删除关系。恢复合法输入后重新生效。一个中轴不变边界上的手动 pair 也必须镜像不变；否则它实际上需要两组关系，与本版“一条边界最多一组”冲突，明确拒绝。

## 当前几何管线

```
Source Point / Curve / CurveSpan
  → unchanged Natural Coons / triangular transfinite Patch
  → exact-boundary relations
  → shared transverse targets FROM Natural pair
  → whole-Patch fairing
  → existing Fullness using Fair Patch normals
  → tessellation / 2D / 3D / Contour
```

所有边界位移严格固定为零，公共 seam 不再离开 Source Curve 或精确 subcurve。Source、Fullness 数值和拓扑不写回。

### 共同切向目标

用同一个 source subcurve 参数求真实 cubic derivative。分别从 Natural Patch 的解析一阶微分求 inward transversal，先移除沿 seam tangent 的参数 shear，再归一化。两侧 inward 方向转成穿越 seam 的相反 path orientation，使用等角权的共同横向轴。各自保留原横向长度和沿 seam 分量。

没有固定 90°，也没有 Curve Plane 的硬约束。方向退化或两侧无法稳定定向时报告失败，不任选 world axis。

### 整张 Patch fairing

保留原 Natural evaluator，以 **12 次 Bernstein 内部位移控制网**表达整张面的派生修正。Quad 使用 tensor basis，Tri 使用 triangular basis。边界控制系数直接消元为零；分别有 121 / 55 个三维内部系数，不是 radius/band 中的一圈显示顶点。

最小二乘能量包含：所有内部系数的正 fidelity、全控制网 Laplacian fairness，以及源面横向导数到共同目标的残差。基础设施复用 PCG；固定目标下 XYZ 不耦合，可分别求同一 SPD 系统。没有沿用旧 Q seam energy / movable seam / 三圈 band。

每条 seam 取 39 个 solver samples。端点 15% 范围内逐渐弱化导数残差，行权重为 `100 * min(1,t/.15,(1-t)/.15)^3`。这是沿 seam 的端点衰减，**不是空间支撑半径**；位移网覆盖整张 Patch。共面且无需修正时直接走 Natural no-op。

Bernstein 修正有解析一阶导数，Fullness 从 Fair 的 position/du/dv 计算法线，不从折线网格估计法线。既有平方 Bubble、0.15 scale、Head Origin 与单面 normal sign 规则保留。Fullness=0 无额外位移，boundary position 和一阶行为仍不被 Fullness 改变。

这是 **numerical G1-like**，不是 analytical strict G1：有限采样拟合、端点弱化以及多条边的角点兼容性仍会带来误差。

## 增量与 Worker

Natural differential、参数环映射、seam target、每张 canonical Fair Patch、basis weights、最终 evaluator 和 tessellation 分层缓存。

- Fair key 不含 Fullness、相机、显示精度、名称或 selection。
- A 的 Natural 改变时，依赖 A 的 seam targets 和相应 Patch key 改变。
- Fair B 改变不进入 B–C target key，因而不会把更新强制传播到 C。
- Worker 内按逐面 key 复用解；一个 active + 一个 latest pending。
- 最终 tessellation 使用 **逐 Patch**求值标识，不使用一个全局 field token 使全部面失效。
- Fullness 仅重用 Fair，再生成最终曲面；浏览器测试其 `smoothDispatches=0`。
- Contour 继续固定精度、Worker resident surface、camera-only 小消息，未改 renderer 架构。

## 失效与边界

源导数退化、横向方向不稳定、数值求解失败时，该 Patch 回退 Natural，并保留显式关系。Inspector 显示原因。未达到中段角度目标也显示诊断，不把 PCG 收敛当作质量通过。

端点附近允许残留角差；不解决 CAD vertex compatibility。没有自动填洞、T-junction、部分重叠平滑或严格全局自交保证。低显示精度仍可能显示离散折面；这不改变求解精度。

## 修改路径

- `src/domain/continuity/{model,basis,solver,evaluation,service,worker}.ts`：关系、整面求解、逐面缓存与 Worker。
- `src/domain/patches/{geometry,fullness}.ts`：Fair → Fullness，所有渲染路径共用。
- `src/domain/geometry/{revisions,dependencies}.ts`：自然输入 key / 删除关系修复。
- `src/domain/landmarks/{model,persistence,presets}.ts`：版本、显式关系与旧设置迁移。
- `src/app/{store,App,styles}.tsx/ts/css`：关系动作、Undo、版本和显示样式。
- `src/ui/smooth/SmoothControls.tsx`：原布局入口替换为 continuity 状态与按边界 Inspector。
- `src/ui/{session,patches/BoundaryAuthoringOverlay,inspect3d/InspectView,edit2d/DerivedRenderLayer,windows/ContourPanel}`：瞬态 hover、逐面更新和新结果订阅。
- `src/domain/contour/source.ts`：消费同一 Fair + Fullness 结果。

旧 `domain/smooth` 的 field/lattice/solver/evaluation/service 不在 active rendering / solving path；仅 PCG 是复用数值基础，旧 model parser 用于一次迁移。历史算法测试保留并使用 `src/tests/legacy-smooth-runtime.ts`，旧 UI 测试归档于 `tests/archive/smooth-v042.spec.ts`，不冒充新系统验收。

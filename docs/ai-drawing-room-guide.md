# Contour Drawing Room：AI 操作与资产语义手册

校对版本：V0.13.0，2026-09-25。对象是独立的二维 Drawing Room，不是 HeadSet/Eyes 建模，也不是 Recording Room。旧阶段文档中的笔触、尖点、图层隐藏规则不一定适用于当前版本；本页记录当前源码及本次实测。

## 先读这段

**迭代方式（用户 2026-09-27 指定）：默认只更新和验证本地版本，不自动部署 Site，也不推送 GitHub；只有用户明确要求发布时才发布。**

**发型生成间 V0.14.16：任何视角都按普通二维 Bézier 编辑，发网只提供深度与转头变形。** 不要再限制为正视编辑或“反推一个截面角”；不要在仅转动相机时重新贴面。每次几何编辑以当前视角整线射线投影，两个 handle 独立；共享端点仍在壳上。编辑视角的二维形状保持原样，其它视角使用单段 cubic 近似。旧发型在实际编辑前保留原形。超出壳的投影范围须明确提示，不要静默扭曲成另一个截面解。详见 [当前发型规则](v0140-hairstyle-room.md)。

用户的资产是可编辑矢量：共享端点、cubic handles、派生连续笔画、独立填充、显示区间、端点笔触和遮挡顺序共同组成结果。**不要仅按截图描一份新图；不要为了转头把它烘焙为位图；不要按视觉相似度重排或重建 IDs。**

图层同时承载语义和遮挡，不能为了变形方便随意合并图层。变形的语义集合可以跨图层，也可以只包含图层的一部分。画面的左右与角色左右不同：这份正面脸模的「右眼」位于画面左侧。参考图 13 名为 NEAR-FRONT LEFT VIEW；不要擅自给它标定成 15° 或其他精确 yaw。

本轮实验输入为 `基础脸模·正面·v1.1.json`。正式归档的旧 v1 位于 [assets/front-face-v1](assets/front-face-v1/README.md)。实验文件不是替代正式资产。

## 快速操作

1. 使用现有开发服务器；需要隔离实验时另开端口。浏览器本地存储按 origin 隔离。打开文件会替换当前工程，先保存用户正在编辑的状态。
2. 顶部「进入绘制间」→「打开」载入 JSON。载入后若回到建模间，再进入绘制间。
3. 「全部收起」压缩图层树；「适配」调整画布。小窗口可「收起右栏」。
4. 对位时关闭图层栏顶部「填充」开关，保留参考图。它临时隐藏全部实色/雾化填充与挖空辅助，不改填充自身的显示设置；开启后恢复。隐藏编辑辅助也遵守此开关。图层的全部显示/隐藏现为一个切换按钮，仍是一次性批量操作，子项可以单独重新显示。
5. 做完几何调整后恢复填充，检查刘海/脸/耳和颈部/衣领的实际遮挡。线框正确不保证成品正确。
6. 数值框 Enter 或失焦提交，Escape 取消。拖动后检查松手结果；Undo/Redo 后也检查画面。

| 操作 | 当前交互 |
|---|---|
| V | 选择整笔或组合 |
| A | 直接选择组内单段、共享端点、handle |
| P | 连续钢笔；新段默认仅绑定，不自动平滑；Enter 结束 |
| L | 拖出椭圆（闭合笔画） |
| H / Space | 抓手/临时平移 |
| Z | 向上拖放大、向下拖缩小；单击放大，Ctrl/Alt 单击缩小 |
| 方向键 | 移动当前可编辑选中对象；Shift 加速，Alt 微调 |
| Ctrl/Cmd+Z；Shift+Z | 撤销；重做（Ctrl/Cmd+Y 也可重做） |
| Ctrl/Cmd+D | 复制 |
| Ctrl/Cmd+X / V | 剪切；粘贴到当前图层 |
| Ctrl/Cmd+G / Shift+G | 组合；取消组合 |
| 列表 Shift | 从锚点到下一行的范围选择；按展开后的行顺序 |
| 列表 Ctrl/Cmd | 增减选择；画布 Shift 复选 |
| Delete | 删除所选；先确认选择范围 |

连接工具在一个按钮中，右键或长按展开；工具可连续执行两次点击。钢笔右键/双击设置后续新笔的默认收尖倍数，不改旧线。新连接的内部端点默认等宽；只有显式启用内部端点笔触才产生内部收尖/延伸。

## 参考图叠底：14 正面 → 13 近正面左视

**线稿和画布先不动，把目标参考格移到原正脸的叠底位置，然后变形对照。** 不要让模型和背景同时移动而失去基准。

这份 v1.1 的参考图是 `full_source.png`，1916×821，缩放 600%，旋转 0，透明度 45%。原偏移：

```text
X = -7.009956532170089
Y =  0.18427168823089846
```

13 格在 14 格左侧，相差约 280 原图像素。保持 scale/Y/rotation 不变，只把背景 X 改为约 `-4.73020705409`，即可把 13 移到原 14 的位置。先解锁参考图，设值后重新锁定。当前背景最大缩放 1000%。不要把这一特定文件的数值当成所有参考图通用值。

换算依据：`k = 2.6 × scale / imageWidth`，本图为 `15.6 / 1916` 世界单位/原图像素；背景横移 `280 × k`。这是参考图的配准，不是头部几何变形。九宫格/多格图先保持共同比例，再按语义点微调配准，不能为每只眼单独缩放参考图。

## 当前脸模的语义与遮挡

v1.1：18 图层、208 曲线、230 节点、46 派生笔画、25 填充、135 接笔关系（51 Smooth / 83 Cusp / 1 Arc）、4 端点联动、17 组显示区间（26 段）。按列表从前到后绘制层级为：

```text
呆毛 → 中央刘海 → 右刘海 → 左刘海 → 鼻部 → 嘴部
→ 右眼睑 → 右眼内结构 → 左眼睑 → 左眼内结构
→ 右眉 → 左眉 → 面部底形 → 右耳 → 左耳
→ 左侧后发 → 右侧后发 → 颈部与衣领
```

| 语义部件 | 变形/编辑原则 | 特别保留 |
|---|---|---|
| 单侧眼睛 | 眼睑与眼内结构先共同对位，再局部修眼形 | 瞳孔、虹膜、主/辅高光、下缘柔光之间的关系；不要只移动眼睑 |
| 刘海与后发 | 分别变形；相邻发片还需检查根部与覆盖范围 | 发尖 Cusp、显示区间、白底遮挡；不能统一当一张头发贴图 |
| 眉/鼻/口 | 各有独立的语义位置与风格变形 | 小幅转头不等于所有点统一横移 |
| 面部底形 | 眼角/耳根/下颌/下巴帮助定位 | 白色填充对耳和后发的遮挡；面部轮廓显示区间 |
| 耳 | 远耳压缩、露出范围变化；近耳可更完整 | 耳外廓白底与内部线不同；隐藏墨线不等于删除耳形 |
| 颈部与衣领 | 同一绘制层内仍是不同运动部件 | 「衣领后缘」`depthOffset=-1 / PARENT`，位于颈部底形之后 |

另一个明确例子：左右虹膜边线有 `+1 / PARENT` 深度偏移，需保持与下缘白色柔光的覆盖关系。新 v1.1 的「白色填充 24/25」实际属于左右虹膜下缘实白底，名称仍泛化；未来可改为语义名，但不要据名字创建重复填充。

精确 IDs、每层笔画、曲线和深度目标见实验 [asset-map.json](../artifacts/view-transition-lab/asset-map.json)。它是本次快照，不是需要运行时同步的另一套权威数据。

## 显示区间必须独立处理

显示区间只控制墨线露出，不修改源 cubic，不破坏闭合填充。适用于单段、连续和闭合笔画，一笔可以有多段。区间端点是沿整笔滑动的切口，不是曲线共享端点。当前可用属性中的起止百分比，或 A 工具下的区间标记调整。

需要分清三种动作：

1. **改形状**：移动节点/handle，改变边界几何，填充随之变化。
2. **改露出范围**：滑动显示区间端点。用于下睑只露一小段、远耳线被发片盖住、发根留白等。
3. **改前后遮挡**：列表顺序、填充、单段 depth offset。用于衣领包住颈部等。

别用第 1 种强行代替第 2/3 种；也别用显示区间掩盖真正错误的脸型。

存档里的区间位置是整笔弧长比例。**大幅不均匀变形后，保持比例不变，不等于保持在原 cubic 上的同一位置。** 实验先将切口定位为 `(source curve/piece, local parameter)`，随源曲线移动，再换算为目标整笔的弧长比例；之后才做有意的显隐修改。生产软件尚未加入这个批量变形配套功能。

闭合路径 `start > end` 表示跨过环起点，不得直接 sort 两个数。开路径反向锚点也合法。完整环 `[0,1]` 与空区间不能混淆。同一笔的多条 track 最终合并为覆盖区间；边界的笔触应保留。未来跨姿态插值时，应保持 track/range ID 和对应方向；跨 0/1 接缝需展开到同一圈数后插值。区间新增/消失需要单独定义过渡，不能把删除 track 当作“全隐藏”——没有 track 默认是全显示。

## 数据层不变量

- `drawing.nodes` 存共享位置；`curves.nodes` 引用 IDs。handles 为绝对二维坐标。
- 同一共享 node 只变换一次。EndpointLink 的不同节点必须仍然重合。
- Bind 合并位置拓扑，派生连续笔画；EndpointLink 只联动位置，不改变笔画/层结构。
- Smooth 要求两侧 handle 反向共线；Cusp 当前是墨线尖接，不再是夹角约束；Arc 保留原曲线，派生裁剪与过渡弧。
- 直接插值两帧全部 handle 坐标，不自动保证中间帧 Smooth。需要共享切线方向＋两侧长度，或插值后约束投影。
- Fill 引用完整有向边界。边线隐藏、显示区间变化不应让填充消失。透明填充只对本层填充挖空，保留墨线。
- 图层/组合显示与锁定是一次性批量操作，之后允许单个成员覆盖；不是不可覆盖的祖级开关。
- 深度 offset 不改变列表/所有权。`PARENT` 与 `LAYER` 是不同基准，只在选定层级的同级列表中移动；不能自动跨到更高层，也不能追随其他对象 offset 形成循环。
- `layers[].items` 与曲线连接顺序不同。渲染使用 `depthPaintBatches`；不要把按 cubic 链遍历的顺序拿来替代画家顺序。
- 持续变形应保存几何真值，避免同时维护两套会互相打架的最终坐标与 deformer 状态。

## 本次实际遇到的限制

- V0.12.38 已有「四角变形」工具：选图层/笔画/组合，拖紫色四角，完成后 A 调端点和 handle。完整图层包含隐藏高光边界，保留显示状态；锁定仍阻止变换。V 的原有平移/缩放/旋转同样放行完整容器中的隐藏成员。
- 四角变形保持普通 cubic、关系和遮挡树，结果直接保存为可编辑几何。显示区间随材料位置迁移。详细用法与近似限制见 [四角变形](v01238-quad-deform.md)。尚无多姿态动画时间轴，也没有持久 deformer＋残差双层动画数据。
- 多选完整的眼睑层＋眼内结构层可以共同变形。不要为此删高光或打开隐藏边线。只有不完整的隐藏成员选择、锁定成员或外部依赖限制才可能阻止编辑。
- 将多层绑定为运动部件，不应以改动 paint hierarchy 为代价。
- 稀疏点拟合误差小不代表发片轮廓和遮挡已经好看。检查 filled preview、原位叠底和中间态，尤其远眼、刘海根部、耳根、下巴、衣领。

## 视角快照（V0.12.39）

绘制间顶部「保存为新快照」保存完整姿态，继续编辑不会自动覆盖。调整完成后另存新视角，或明确「更新当前快照」。下拉切换，有未保存修改时先另存/丢弃/取消；所有操作可 Undo。切换还原曲线、显示区间、填充、深度 offset 和背景对齐，保留对象 ID。

这是姿态检查点，不绑定 yaw/pitch、不自动居中。录制间为姿态设置整体 placement offset 与 yaw/pitch 并求值插值；操作见 [快照录制间](v0130-snapshot-recording.md)。不要把快照的画布观察 pan/zoom 当成姿态位移；节点坐标原样保存，背景自身的位置/缩放也保存。新增/删除曲线目前只改变当前画布，不自动同步其它快照。

数据在 project.drawingSnapshots；普通编辑只改 project.drawing。库中参考图片共用，避免每存一个姿态复制整张九宫格。实现：src/domain/drawing/snapshots.ts、src/ui/drawing/SnapshotBar.tsx。详见 v01239-drawing-snapshots.md。

## 快照录制间（V0.13.0）

录制间只录入完整快照及整体平移，不再编辑点、线或 handle。左画布保留可调透明度的只读头壳参考；Yaw/Pitch 滑条、地图和「旋转视角」模式同步到同一真实 HeadFrame-local 相机。绿点选择已录入姿态，空白地图只导航。姿态属性角度修改该记录，底部滑条不修改记录。

缺少角度支撑的元素保留最后有效位置并标红，不进入右侧最终预览；不要自动填满 coverage；V0.13.11 允许作者选择未覆盖曲线，明确生成指定目标姿态的推断草稿，再 Apply 到快照，操作见文末。图层/填充/雾化/显示区间由 Drawing 渲染器保留，快照的绘制顺序仍然就是遮挡语义。

从绘制间修改完姿态，点击「更新当前快照」后录制间自动同步全部来源引用，不需要手动刷新。录制角度、整体平移和自定义姿态名称保留；尚未保存到快照的草稿不参与同步。更新及全部录制引用一起 Undo/Redo。来源删除后保留最后同步内容并提示；打开旧存档时优先使用仍存在的来源快照。旧 project.recording 在 load/save 时删除；新字段是 project.poseRecording。左右 yaw 分别录制，不自动镜像。

## 显示性能与效果边界

矢量源数据始终保留完整 cubic 精度；Drawing/Recording 的笔触外轮廓允许按显示尺度减采样，放大时加密。区间定位、圆弧裁切、连接关系和存档不能跟着降精度。渲染器缓存结构顺序，不能把图层遮挡、深度 offset 或端点笔触混入错误的缓存键。完整数据和复现见 [录制性能](recording-performance.md)。

线条「像素笔触」现已替换旧轮廓雾化：选线 → 右侧「描边与填充」→「像素笔触」，调整软边宽度（0.25–3 px）和笔触强度（0–100%）。这是线级样式，可多选批量设置；关闭/0强度为原生矢量边缘。保留实心主体和尖端，窄范围灰阶软边伴随固定的轻微漂移，不是颗粒、大雾或像素方块。旧开启雾化的线在读取时自动映射到新效果；源节点、handles和快照不被重写。新编辑数据写入 mist.mode=INK_EDGE。瞳孔/虹膜的雾化填充保留内外侧扩散语义，它与线条边缘软化分开处理；当前脸模只开4个眼部填充与全关雾化的转视角性能基本相当，不能因此假定任意尺寸或数量的雾化填充都免费。

显示区间的端点笔触也参与录制插值：先按各来源实际线宽换算收尖距离，再插值收尖/延伸；闭环接缝无额外笔尖。不要把 taper 与 taperWidthScale 分别线性混合后同时写入，否则绝对 taper 会覆盖倍率，导致尖端变平。

## 仅恢复某一图层

图层标题行的回转箭头「从快照恢复图层」会弹出来源快照选择。按相同图层 ID 恢复完整成员和属性（含填充、组合、连接、区间、笔触、显隐），用于从正面重新 deform 外发等。保留当前图层位置、其他图层、背景对位和 active snapshot；不是全画布切换。可以 Undo。恢复后只是草稿，作者确认并「更新当前快照」才同步 Recording。

来源中没有此层的选项禁用；已被移到其他层的来源对象不自动抢回。跨层端点不能保持重合时在确认前提示解除，其他层几何不动。见 v01239-drawing-snapshots.md。

## 显线 / 断线区间

选曲线 → 属性「显示区间」→ 新增区间类型选「显线区间」或「断线区间」→ 添加。已有区间也可单独切换类型。嘴唇中间的缺口直接用一段断线区间，两端沿曲线滑动即可，不必写两段显线。多个显线先取并集再扣除断线；仅有断线时从整条线扣除。不同区间的端头用不同颜色，同一区间的 A/B 两端颜色一致，保留 1A/1B、2A/2B 编号；颜色不代表显线或断线，类型看属性或标记提示。两种方式都不改变填充、节点或 handles。

缺口两边的笔触由对应区间端点控制；延伸会伸入缺口。更新快照后 Recording 同步，新缺口先局部收细，再从中点打开（开口路径端部则从端部缩进），保留对应笔触收尖长度；不要把 HIDE 缺失帧当 full-length gap，否则会把整笔隐藏。旧 mode 缺省为 SHOW。

录制插值先将同一笔画的区间统一方向和接缝；开放曲线 A/B 互换时同时交换两端笔触，不会让区间在中间角度缩成零。优先按区间 ID 对应，重新创建但明显重合的同类型区间也会对应（弧长域交并比至少 50%，且没有同样可信的竞争区间）。同类表达仍不强行匹配不同笔画、不同连接拓扑或有歧义的区间；新增/删除仍从中点展开/收缩。跨快照混用显线/断线时，按下方 V0.13.8 的实际覆盖规则处理。匹配只用于求值，不改原快照或编号/颜色；对应结果按快照缓存，转视角不重新匹配。复现：`artifacts/collar-gap/view.html`。

### 端点拖动的方向跟随（V0.13.7）

双击或右键左侧「直接选择 A」，在「方向跟随」中输入 0–100% 并应用；默认 40%，0% 完全保持原柄方向。之后用 A 拖动端点，直接相邻的柄会随端点间连线的转向适度旋转，柄长不变。Smooth 两侧共同转动保持反向共线；Cusp、仅绑定、圆弧源线各分支自由跟随。正常端点/镜像轴吸附仍先确定精确位置。

这是本地工具偏好 contour.drawing-direct-follow，不是作品关系，不进入快照或录制插值；实际拖动产生普通 cubic 坐标，可一次撤销/重做。修改设置不会重算已有曲线。方向键与数值位置输入仍只平移，手动拖柄也不受该偏好影响。接近重合端点/方向翻转时会减弱跟随，避免跳动；不要将它误认为自动 Smooth。

### 显线与断线是两种编辑表达，不是两类动画资产（V0.13.8）

例如一个快照用「断掉中间」，另一个用「只显示两侧」，录制会先算出同一套实际可见范围，再自动对应；不得让旧缺口收缩、同时让新显线伸展，从而把双方都隐藏的中段露出来。开放路径的 A/B 自动按共同弧长方向整理，笔触随物理边界交换；闭合路径保留作者选择的那一侧弧段，并处理循环接缝，不能简单取最短弧或把 start/end 排序后误选补集。

此转换不改 Drawing/快照存档，用户无需重建区间。若两姿态使用同类表达，仍优先稳定 ID，再按弧长重合匹配重建的区间。混合表达则比较并集减去断线后的覆盖状态及其边界笔触；新的独立缺口才需要从中间出现。排查时比较整个范围的 mask，不能只比较 range ID、数量或 start/end 数字。


## 区间笔触的出现与消失（V0.13.9）

区间端头仍沿线移动，收尖长度保持作者设置的 px / 线宽倍率。不要为了短区间而压缩收尖长度、强行维持满线宽；两端收尖重叠时，应自然变成细尖并消失。普通曲线的外端点短线适配与此分开。

录制中新出现的断口不能先硬切再长出笔触：先在完整线条上生成局部收细，再打开缺口；反向合拢后恢复宽度。`intervalPinch.ts` 的 WeakMap 仅承载这段求值期包络，不是新的存档属性。`displayField.pinches` 需传给矢量渲染器，并进入 inkRuns 缓存键；深度分片与普通渲染共用此包络。明确为 0 的收尖仍尊重硬切。


## 缺失曲线的姿态推断（V0.13.11）

1. 在录制间点击未覆盖的红色曲线，或展开「未覆盖元素」点选曲线。
2. 在「推断缺失姿态」选源录制姿态，勾选一个或多个目标录制姿态（Yaw/Pitch 均支持），点击「生成推断草稿」。目标必须已录制，且尚无这条曲线；不要先创建不同 ID 的替代线。
3. 草稿会参与录制插值，但不修改绘制快照。目标处的完整几何使用青色虚线辅助显示，右侧最终预览仍隐藏；切到两姿态之间观察逐渐显现。默认随机选 A/B 一次，保存后不重抽；草稿卡片可改方向。
4. 「应用到快照」只将该曲线、必要连接和专属断线区间写入对应来源快照；每个目标分别 Apply。若该快照当前正打开，也补到当前绘制草稿，保留其它未保存修改。一次 Apply 一次 Undo；生成、删除草稿、改方向也可 Undo，草稿随 JSON 保存。
5. 去绘制间切换该快照，从列表选线，展开「显示区间」；标有「仅此曲段」的全覆盖断线区间控制新线，不隐藏同笔相邻发纹。可拖动区间、改 A/B 显现方向及端头收尖；更新快照后录制自动同步。

推断以同图层共同 curve ID 的四个 cubic 控制点拟合平均二维仿射趋势；退化时降为相似变换/平移。它是起始位置建议，不是精确的头部三维重建。Recording 的整体 placement offset 不参与拟合。已绑定的端点贴合目标中相同相邻端点，仅调整新线；现有节点和 handles 不移动，原曲线 ID、已有图层顺序和深度规则保留。

草稿字段 project.poseRecording.inferences；运行时 resolvePoseInferences 在快照同步后覆盖求值副本，不把推断伪装成源快照。Apply 才写 drawingSnapshots。没有共同图层曲线、目标层缺失、目标已存在同 ID 等情况明确报错；批量生成原子完成。当前不推断独立 Fill/Offset 对象。跨组织组合连接、以及目标连接笔画同时存在 ARC 和整笔区间的情况会提示先整理，不做破坏性猜测。

专属区间使用 scope=CURVE，仍按弧长表示 start/end；revealFrom 指物理 A/B，用于该区间在另一姿态缺失时收缩到对应远端。全隐藏到可见保持完整收尖长度，短的可见段自然由细尖长出。普通整笔区间的无方向匹配、闭环循环和先收尖后断开保持原规则。复制与精确分割也必须保留曲段范围；不要把新线的全隐藏区间扩展到整笔。

复现夹具 src/tests/fixtures/inference-three-poses.json 来自用户「基础脸模三视角.json」的左刘海/颈部与衣领，剔除了参考图和其它层。浏览器实验页 artifacts/pose-inference/view.html（不随网站部署）。


### 推断区间继承源端点笔触（V0.13.12 修复）

推断曲线的自动断线区间使用源曲线实际生效的 A/B 端点笔触，不再额外添加 20 倍线宽的默认收尖。源端为 0 就为 0；绑定内部未启用的旧默认值仍为 0。短线的倍率收尖先按源笔画原有规则换成实际可见长度，避免同为 20 倍却在区间上失去短线适配而明显变细。延伸距离也来自对应源端。

HIDE 区间低端结束左侧可见线，因此使用源 B；高端开始右侧可见线，因此使用源 A。移动中的断线端头替代已经被遮住的原端点笔触，不叠乘第二次收尖。双方向、不对称收尖/延伸以及接近完整显现时都应保持一致；原始几何、源端点设置不改。

新草稿保存 sourceInkEnds，Apply 后在曲段区间标记 inferenceInkVersion=1。旧草稿加载时补齐；旧已 Apply 的推断区间只修正可识别的自动 20 倍默认值，保留区间位置和明确修改过的笔触，标记后不重复迁移。手工普通显示区间不受影响。

### V0.14.7 角度比较与正视生成规则（取代上面的 V0.14.4–6 发丝规则）

外侧可见末端 Y 差 ≤0.05R。中央共享尖点在较低外端下方 0.01–0.05R，有横向随机；两条中央角各 20°–40°。中央和内部发纹都只显示发梢侧最后 10%–20%。额外线位于中央两根之外，均分后扰动，至少间隔5°；容量不足有 UI 提示，已有线暂时休眠而不删除，扩大范围恢复。每根仍只有一条 cubic。

裁切先按正面弧长确定 Bézier t，再按当前投影换算成 Drawing 弧长比例，确保转视角时裁切端不沿三维发丝滑动。所有可变随机由保存种子派生，只有重新生成才重抽；添加会按新数量重新均分槽位。右侧是独立发型 Contour/图层，不修改主 Drawing。详情以 [发型说明](v0140-hairstyle-room.md) 为准。

### 四边曲线变形器（2026-09-29）

### 组装间：区域变形与单线微调（2026-09-29 更新）

当前日常流程是：选择角度与图层 →「区域变形」→「编辑区域变形器」；同一个框的角调透视、边和边柄调弯曲。两项可一起复制、套用、重置。要进一步调整下颌等单线，点击顶部紫色「单线微调」，按 A 选段后拖端点/控制柄，最后「更新此姿态」。这是整体变形之后的修正，绝不能用直接修改 `assembly.drawing` 来替代。

### 区间的角度开关（2026-09-29）

属性中每个显线/断线区间都有「启用此区间」，姿态模式下修改后按「更新此姿态」记录。关闭保留位置与笔触，只暂停该区间，其他区间正常生效。例：0° 关、30° 开，0° 到 30° 前一直关闭，到 30° 开启；负 Yaw 从基准向外同理。开关是保持型状态，位置仍正常插值。顶部「显示区间」只是预览开关，不会写入姿态。原稿编辑修改共用区间，不能替代当前姿态修改。关闭区间的 V 抓手会淡化，仍可修改并再次开启。

组装区间排错：同一笔画在两角度的区间 ID＋模式一致时，必须保留原始通道插值，即使同时含 SHOW 和 HIDE，也不能先转成全显线＋新编号的断线集合；否则移动缺口可能被误判成新旧两条缺口。不同 ID/不同显隐表达仍使用既有对应与覆盖归一化逻辑。见 `src/tests/assembly/interval-identity.test.ts` 与 `tests/e2e/assembly-interval-identity.spec.ts` 的下颌 60°–90° 回归。

旧存档区间 ID 可能被历史 coverage 转换更换。先在原始区间上完成稳定 ID/保守空间对应，再判断是否同一套 SHOW/HIDE 表达；不能把“原 ID 不同”直接当作需要覆盖转换。37° 下颌回归扫过 0°–90° 全部相邻关键帧，并验证插值位置编辑保存后仍不增殖。

# 2026-10-05 性能阶段结论

本轮保留共同绘制产品缓存。真实浏览器中的单柄局部编辑收益在正、反两种执行顺序都出现；全部曲线同时变化时有回退，因此不称为所有操作全面提速。计算代码冻结于 `de6f535`，已发布 v93 的生产源码相同；`578f566` 只增加可复现的双版本诊断构建。

## 同一内核与作用范围

Drawing、Recording、A/V、线组和整层变形仍使用共同目标、依赖计划与 `PaintScene`。选择确定直接作用范围，LINK/SMOOTH、材料路径、动态域成员等真实依赖扩展范围。每次手势以冻结起点求解；0° 固定、已有校准、原子失败、保存与一次 Undo 继续是约束。

新增 `paintProducts.ts` 只复用世界坐标纯绘制产品。原生路径检查完整值依赖，不把可变 Drawing 身份当证明；屏幕格式化、相机、事件及选择仍读当前数据。持久 affine/Coons 输入保留原始权威程序与 canonical 求值，未知依赖保守回退。详见[实现与 74 组完整 SVG 对照](../../artifacts/paint-products/report.md)及[作用范围原则](curve-scope-performance-principles.md)。

## 测量口径分开

单位为毫秒；浏览器行的斜线为 p50 / p95，Node 行为 prepare＋display 的合并样本中位数。没有把不同工作量、不同环境的数字拼成端到端延迟。

| 工作量 | 前值 | 后值 | 支持的结论 |
| --- | ---: | ---: | --- |
| 同一云浏览器，121 曲线正脸，一条曲线的一个柄：目标构造加同步显示 | 9.7 / 12.2 | 6.4 / 8.2 | 局部工作中位下降约 34% |
| 同一单柄场景，只绘制预先产生的目标 | 8.6 / 10.5 | 5.6 / 8.1 | 绘制复用有效 |
| 同一浏览器，整份 basis 持续变化加 19 洋葱：求值加显示 | 54.7 / 61.0 | 59.3 / 69.2 | 回退保留，未解决 |
| Node，耳根 X 目标反推及当前显示准备 | 20.77 | 15.84 | 共同求值阶段的同任务 CPU 改善 |
| Node，耳根 Y 回退目标 | 17.78 | 13.98 | 同上，不含浏览器绘制 |
| Node，轮廓 Y 回退目标 | 15.04 | 12.86 | 同上，不含浏览器绘制 |

单柄浏览器用 v91→v92→v92→v91 四份新报告，12 个 pass、288 个可见测量帧；每版本每类 48 个样本。全部同一公开内置脸、同一手势起点、零洋葱、无填充，没有用户私档。顺序不同仍改善：正序整体 10.1→6.6，反序 9.4→6.4。计时不含反推、输入分发、事务或完整光栅化；rAF 只是回调机会，不能称为 FPS。冷准备耗时结果混合，没有冷启动改善声明。

此前整场景矩阵每版 21 个 pass、504 帧：七组中六组整体中位数变慢、五组仅绘制中位数变慢。局部收益不覆盖这个结果。正侧游标先前约 2.71 ms 的差异也保留；一次分阶段检查未确定原因，不据此继续猜测式修改。

一次只读 all-miss 归因测得每帧 32 产品全部失效：签名与键约 1.698 ms、Map 操作 0.505 ms、复制 0.315 ms。重复全局键片段占字节 33.5%，但没有独立耗时证明，不能换算成预期收益或解释整个 4–5 ms 回退。此阶段停止微调，生产代码未再改。

## 正确性与真人验收

- 最终生产候选的相关聚合为 **44 文件、419/419 通过**，包括启用私有回归后的五项；TypeScript、正常构建与诊断构建通过。这不是全仓库所有测试通过。早期检查中的六项旧事务夹具、五项退休模式洋葱夹具失败已在未改基线复现，本轮未修复它们。
- 74 组独立旧内核冷基准 SVG 一致。19 个旧暖序列步骤存在旧 ARC/offset 身份缓存陈旧值；新结果匹配独立冷基准，不能伪称与这些旧暖输出完全相同。
- 原生主应用：Drawing/Recording 单柄、相机 pan/zoom、保存、全局 Undo；两次中间角校准后 0° 画布保持，既有 −60° 最终 57 条 SVG 路径、88,011 字节完全相同，九个真实视图不增。
- 线组及整层 cage 在 v91 真实保存与 Undo 均通过；v92 另复验线组，整层以 v91 及本版自动化共同内核检查为证，不冒充重复真人验收。v91 的 V 多曲线平移也通过。
- 测试操作均撤销，主应用回到原空录制现场。原拥有画稿导出字节一致；该导出不包含整个引用工程，不能扩大为全工程 JSON 完全相同。正常 SaveJSON 按钮未产生可取得下载，原因未确认；本轮通过可见应用导出与预览命令核对源稿及最终 SVG。

## GPU 与交付边界

没有加入 GPU 后端。本云浏览器 WebGPU 没有可用适配器，WebGL2 上下文也不可用，这不代表其他电脑不可用。当前剩余包括依赖准备、材料、React 与同步提交，不能用少量插值算术的速度推断整体 GPU 收益；传输、同步、拾取与精度尚没有硬件测量支持。用户的条件授权仍保留，但本阶段没有达到实施收益证据门槛。

最小改动回退仍限 0 到主轴 ±90 的边，二维内点／继承表达式未扩展；复杂 ARC／复合路径在手改材料后分段的已知限制仍暂停。没有新增 Frame 或旧录制迁移。

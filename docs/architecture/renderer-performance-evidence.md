# 共同绘制器的性能实测

本阶段从实际浏览器中找出重复读取，再优化 Drawing 与 Recording 共用的 `PaintScene`。没有为 A、V、曲边框或洋葱另写绘制算法。

## 已发布的变化

v90 的主画面每帧重新计算 481 次 stroke key，建立 37 次连续关系索引。求值时的临时读取作用域早已结束，React 绘制时没有复用它。

v91（源提交 `0ea573e`）让 `PaintScene` 的一次同步准备拥有自己的 `withDrawingReadScope`。索引在本次读取内复用，当前坐标、显隐和材料仍取当前 Drawing。可变 Drawing 不会因此被永久缓存。真实浏览器计数确认，上述两项重复工作均降到零；每帧仍建立两个当前文档读取上下文。

对应实现与验证：

- `src/ui/drawing/PaintScene.tsx`
- `src/domain/drawing/readContext.ts`
- `src/tests/drawing-paint-read-scope.test.ts`
- [Node 对照与完整 SVG 一致性](../../artifacts/paint-read-scope/report.md)

自动化覆盖可变对象原地修改、坐标／拓扑／显隐／材料变化、填充与挖空、拾取路径，以及线组和整层的 affine、四角、曲边域。30 份完整 SVG 与四个独立进程中的 768 个测量帧哈希一致。聚合 409 项通过后，同一提交独立启用并通过原先跳过的 5 项输入回归，共 414 个不同测试通过。

## 浏览器对照

两个版本使用同一云 Chromium 会话中的公开内置正脸：121 条曲线、135 个节点、13 层，两侧眼耳可见。每版 21 个 pass、504 个前台测量帧；配置、环境和全部场景／路径数量相同。使用 React 生产 profiling 构建。

下表是毫秒的 p50 / p95。固定基点只切换观察角度；变化基点是整份基点数值持续变化的合成负载，不能冒充一个柄的拖动时间。

| 工作量 | v90 | v91 |
| --- | ---: | ---: |
| 固定基点、无洋葱，仅绘制 | 17.2 / 22.1 | 13.7 / 17.6 |
| 固定基点、19 洋葱，仅绘制 | 19.0 / 21.3 | 14.4 / 20.8 |
| 固定基点、19 洋葱，求值加绘制 | 27.7 / 32.8 | 24.5 / 30.6 |
| 变化基点、无洋葱，仅绘制 | 17.5 / 21.3 | 12.4 / 13.3 |
| 变化基点、19 洋葱，仅绘制 | 20.6 / 23.4 | 14.3 / 20.8 |
| 变化基点、19 洋葱，求值加绘制 | 59.5 / 64.5 | 54.7 / 61.0 |
| 变化基点、19 洋葱、填充，仅绘制 | 22.9 / 26.3 | 17.9 / 31.1 |

七组仅绘制的中位数均下降 20–31%。这不代表所有延迟都改善：变化基点加 10 洋葱的整体中位数从 44.3 升到 46.4；填充组的仅绘制 p95 也上升。两版求值阶段执行次数相同，本次没有修改求值器。完整对照应保留这些结果，不能只挑改善项。

测量包括路径构造、React 与同步 DOM 提交，不包括输入分发、反推、事务、编辑器覆盖层或完整光栅化。rAF 间隔只是回调机会，不是画面完成、FPS 或端到端输入延迟。下方部分画布在初始视口外；两版不同 pass 之间的空闲时间也不同。具体时间存在调度和尾部事件影响，工作计数消除是更确定的证据。

公开诊断入口：站点下的 `/diagnostics/recording-renderer-benchmark.html`。它只使用内置与合成数据，不读写用户工程。诊断结果不能替代主应用中 A／V／域、保存与 Undo 的真实操作验收。

## 尚未完成的成本与 GPU 判断

一次有界单柄检查确认，仅一条曲线改变时，墨线缓存为 31 次命中、1 次失效，但仍存在整幅派生几何与屏幕路径格式化。后续应复用共同曲线／材料路径的纯绘制产品，显式维护坐标、关系、域、材料、画笔、相机和拾取依赖；不能用不可信对象身份缓存可变画稿或带事件的旧 React 树。这项下一候选尚未计入以上收益。

正侧角度的一项旧 CPU 对照观察到约 2.71 毫秒回升。后续单次分阶段检查没有证明新键逻辑导致它，均值与中位数排序相反，峰值落在不同角度。因此该观察仍保留，但不据此继续猜测式微调，也不声称所有路径更快。

本云浏览器暴露 WebGPU API，但没有返回适配器，WebGL2 上下文也不可用。这不是对其他设备能力的结论。没有修改浏览器安全设置或实现未经验证的 GPU 路径。当前明确的 CPU 重复工作已有可测收益；GPU 后端需要在可用硬件上连同数据传输、同步、材料与拾取正确性一起验证，现阶段不能承诺其收益。

# 圆弧连接与填充边界

填充仍引用作者的曲线 ID。已采用的贯通路径若把两条线连接为 ARC，笔触和填充从同一份已解析圆弧几何读取边界；不会修改隐藏闭合线、作者控制点、线宽或层序。

## 两个独立闭合面的接缝

每个面保留自己的裁切后曲线，再接上该曲线拥有的圆弧部分。圆弧的归属分界沿用笔触现有的弧长中点。各自内部闭合线的派生端点与邻接柄一起移到该分界，避免闭合路径返回旧尖角而留下楔形填充。

`displayRoutes.deriveDisplayRouteCornerGeometry` 提供共同的连接、裁切和归属几何。`resolvedFillGeometry` 只负责把填充的已选边界连接到这份几何；`appearance.fillGeometry` 是所有消费者的入口。Drawing、Recording、填充拾取、SVG、雾化填充和透明挖空共用该结果。

## 作用范围与失效

- 仅采用第一条有效的已采用贯通路径；未采用、禁用或 SHARP 连接不改变填充
- 显隐区间和隐藏笔触不选择另一个结构边界，填充与笔触显隐仍独立
- 域与仿射形变沿用现有材料程序，先在原材料空间决定圆弧归属，再投影；不从已形变控制点重新拟合圆弧
- ARC 长度预算可能依赖另一端的连接。填充产品缓存因此包含所用整条路径的真实依赖，不只包含本面曲线
- 关系索引及圆弧产品在同一个 Drawing 读取范围内共享；不会以可变作者文档的对象身份作为跨编辑缓存保证
- 真正退化的圆弧、冲突连接或不兼容材料程序保留原有效填充并给诊断；不返回空白脸片

## 保留的行为

填充 depth offset、所属图层、透明挖空作用范围和第三方遮挡不变。自身笔触保护继续使用已有可见墨区产品。滤镜、噪声和自交笔触保护仍保留原有诊断边界；本次不增加第二套栅格或布尔几何系统。

## 验证

`drawing-linked-arc-fill.test.ts` 覆盖独立双面、端点方向、反向边界、共享填充、隐藏及零长区间、长半径裁切、退化端点、局部 ARC、镜像、非等比与保留域、冷暖缓存、命中/SVG、自身墨区保护、挖空、offset 和 Undo/Redo。

公开渲染固定样例同时与修改前版本独立对照：只允许填充轮廓及其挖空、选择、命中副本变化；原笔触、延长线、偏移线命中、作者数据和路径数量保持一致。更新这些有意变化的期望不等同于放宽其他输出回归。

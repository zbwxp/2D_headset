# 录制间的显示区间交互

录制间与绘制间共同使用 `DisplayIntervalOverlay`、`InkEndOverlay` 和 `intervalGesture`。V/A 选中线条后，区间两端和笔触端点使用相同的显示、拾取规则；区间可沿明确连接的跨层路径移动。选中本身不修改文档。

共享手势冻结拖动前的 Drawing 和材料路径。Recording 的宿主只负责通过现有 `prepareSnapshotDrawingPropertyEdit` 接受预览并提交：真实视角把显示坐标映射回作者材料坐标；反推角只更新独立区间端点响应。松手复用接受的候选，失败、Esc、历史变化或视角切换取消候选。不会由一次区间拖动建立新的真实角度快照或几何响应。

原有规则继续适用：start/end 分别插值，HIDE 两端相等时不隐藏任何长度，SHOW 两端相等时没有可见长度；闭合 fullLoop 明确表示全圈。区间类型、全圈标志和末端笔触样式仍按真实视角属性编辑。独立响应可以表达 0–30° 精确塌缩、30–90° 展开，曲线几何仍由原基点插值。世界位置与材料位置之间仍有原有浮点投影精度，不另添间隙或替代插值器。

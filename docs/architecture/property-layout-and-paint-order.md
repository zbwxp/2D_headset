# 属性布局与填充归属

v99（生产代码 `b3c32cf5e22719cb64f40df06967236eaa844d0a`）让绘制与录制共用 `DrawingSidebar` 的上下分栏与拖动调高，以及 `DrawingPropertiesPanel` 的标题、折叠和正文滚动。图层列表在上，属性在下。录制原有的域、宽高、层序属性进入下方面板，所有权和编辑适配保持原有策略。

共享组件显式分配三行，折叠隐藏分隔条后属性不会自动落入零高度行。旧直属元素行规则及录制独有的正文溢出覆盖已经移除。引用来源的只读选择不会显示可写的当前视角属性。

## 两类操作仍有不同用途

- **选择边界曲线**：选择填充或偏移跟随对象引用的源曲线，只改变选择；对象与源曲线的位置、归属、ID 都不改变。
- **移至图层**：改变填充/偏移对象所属层；边界曲线仍在原处。透明挖空作用于所属层全部填充，与该层内排序无关，描边不受影响。
- **深度偏移**：当前仅曲线支持。PARENT 相对所属笔画/组层级，LAYER 相对所属层所在的图层层级。它改变绘制遮挡位置，保留对象归属、连接及隐藏成员的序位。

填充目前没有深度偏移字段、快照属性校验或相应渲染排序支持。本次未添加该功能，也未删除上述操作。未来若增加，应保持原 batch 的所属层及挖空作用域；透明挖空与顺序的关系不能由一个新滑条暗中改变。

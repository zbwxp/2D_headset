## 实际覆盖

| 路径 | 操作与观察 | 结果 |
| --- | --- | --- |
| 纯原稿 A | 未预选时直接拖眉线本体，再拖控制柄；镜像侧同步；逐次 Undo、Redo | 首次拖动生效，历史恢复对应形状 |
| 纯原稿 Pen | 连画两段，第二段拖出控制柄；Esc 结束；逐次 Undo | 显示连续两条新曲线，撤销一段一次 |
| 引用层 A | 用显式“提取图层引用”按钮将嘴部两条连续曲线放入真实 0°；拖柄 | 局部形状与配对侧更新，一次 Undo 恢复 |
| 连续线组域 | 选择嘴部连续笔画，拖曲边框上边中点；保存，再撤销保存和手势 | 曲线弯曲，保存时外观不跳；界面拟合误差约 0.02 px |
| 整层域 | 显式选中嘴部图层，拖框角；保存，再撤销保存和手势 | 整层目标生效，保存时外观不跳；界面拟合误差约 0.01 px |
| 真实 90° | 创建真实视角，粘入同 ID 引用层，V 整层平移并保存 | 原先只读红色预览变成可编辑成员，摆放保存 |
| 60° 修正 V | 在 0°/90°之间整层上移，保存修正，再 Undo/Redo | 角度仍为 60°，只写修正；真实顶点总数仍为原有两列六个，没有新增真实 60° |
| 取消与跨模式历史 | 从录制转到 Drawing，Pen 放第一个锚点后 Esc；Ctrl+Z | 未成段的取消没有占用历史；Undo 跳回 60°并撤销前一笔保存，再次 Undo/Redo 恢复修正 |

线组和整层域均通过同一已发布框工具和事务路径完成。保存指录制的更新/保存修正操作，并非本轮重新导出和加载整个 JSON。

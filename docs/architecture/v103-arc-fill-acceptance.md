# v103：ARC 端点填充验收

生产源码：`1368a40973a4b728eb4c8e00153868aff2d95594`。本轮只修填充对已采用跨端点圆弧的跟随；快照复制、身份家族及三分支轮廓选择不在此版本。

## 自动回归与构建

11 个相关测试文件，163 项通过；TypeScript 与生产构建通过。新增 21 项圆弧填充回归涵盖方向反转、双面共用弧长接缝、共享边界、隐线与显隐区间、长距离裁切、真实退化、镜像、非等比与保留域、暖缓存、拾取、SVG、挖空、层序和撤销。

公开固定场景与原生产源码作独立比较：74 个产品场景中58个、30个读取范围场景中20个有意改变填充路径。所有变化只涉及填充、反向挖空、填充选择或填充命中轮廓。4,265条笔触、尖端延长和偏移线命中路径，以及其他SVG内容、作者数据和路径数量不变。未变化的期望哈希原样保留。

六个真实录制角度的本地回归中，12个脸填充的圆弧部分与已有笔触归属几何一致，两个面共用接缝误差为0；旧尖角到圆弧接缝之间的30个区域采样点不再被填充。私人输入没有进入公共站点或版本库。

## 实际 UI 操作

在v103公开测试站使用内置双脸片例子：

1. Drawing中把跨层圆弧接笔影响距离从13.143px改为60px。两个面填充同时跟随新圆弧，隐藏源闭合线的作者端点不移动。Undo后的实际SVG填充路径与编辑前逐字一致，Redo恢复60px。
2. 提取13个内置图层引用，建立真实0°录制视角并粘贴。Recording中两面显示相同圆弧接缝。
3. 在Recording把该距离由60px改为80px，两面填充一起更新。保存JSON后经生产解析器重读：录制局部值为0.32单位，源快照值仍为0.24单位；两个填充仍闭合且各有一段归属圆弧。一次Undo恢复60px时的实际SVG路径。
4. 测试结束逐步Undo，恢复原空录制和原画稿。导出的整个工程文件与测试前逐字节一致。

Recording粘贴测试曾因工具审批被阻挡；提供既有用户测试授权后，仅重试原调用一次成功。没有替代输入或隐藏API。实际UI检查不等于用户亲自验收，也不替代上面的多角度自动回归。

## 保留限制

无效或退化圆弧、不兼容的材料程序保留原有效填充并给诊断，不会把脸片清空。自身笔触保护的滤镜、噪声和自交限制沿用上一版本。本次未实现复杂三分支的显隐驱动轮廓选择，也未改动旧档的明确层序覆盖。

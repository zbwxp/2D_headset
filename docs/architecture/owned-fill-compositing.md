# 自身填充与笔触的合成

填充继续引用原来的闭合边界。它的层序偏移可以改变对其他对象的遮挡，但不能盖掉同一填充自己的可见边界笔触。其他对象仍可遮住这些笔触；隐藏区间、线条隐藏和独立宽度编辑继续生效。透视与非等比变形改变路径，不为这条规则补偿线宽。

这不能统一转成层序重排。例如，原序列为「自身填充在其他脸片前，其他脸片在自身边界线前」，再要求自身线在自身填充前就形成循环。因此不抬高整层、不在最后重画边界、不重写 offset。

## 共同数据流

1. `depthPaintBatches` 保持原始绘制队列和真实所属层。
2. `createPaintProductReader.fillBoundaryInk` 按 `fill.boundary` 的稳定曲线 ID 查找实际位于填充后面的笔触。每个 reader 只建立一次曲线到队列批次的索引，随后按边界查询。
3. 复用已有 route/member/stroke 产品的可见 `InkRun`，包括贯通路径、ARC 归属、显隐截断和收尖；不以填充边界重新猜一条笔触。隐藏或零显示透明度不产生保护区，正透明度不再乘进笔触 alpha。
4. `fillInkSupport` 使用已有墨轮廓。原生等宽快速路径缺少轮廓时，向现有 `inkRuns` 采样核请求每段 ribbon，并按实际端帽/接头加入半线宽圆盘。没有宽度补偿、额外存档资产或另一套变形算法。
5. `PaintScene` 在填充原来的队列位置，用相交的反向 SVG clip 排除这些自身墨区。笔触和第三方绘制保持原位，填充绘制与填充命中使用同一 clip。选择辅助线独立保留。Drawing、Recording 和 SVG 导出都使用这个组件。

实色与雾化填充使用同一清晰边界保护；雾化侧向、宽度和不透明度保持原定义。透明挖空保留原所属层和作用域，不用自身笔触规则改变它的裁切数学。共享边界的多个填充分别在自己的队列位置合成。

## 明确边界

- 这是名义矢量几何保护，不承诺抗锯齿像素逐字节相同。一次 4 px 笔触本地对照中，开启自身填充后的墨面积由约 50% 恢复到约 96%，仍有约 4% 的边缘栅格化差异；线宽和原绘制墨路径未改。
- 带噪声位移或高斯模糊的笔触外沿不能精确表示为这个矢量 clip。保留原显示并输出诊断，不暗中禁用滤镜、不把半透明 alpha 再乘一次，也不假称完整保护这些外沿。
- 自交墨轮廓可能使非零环绕填充与反向奇偶裁切不一致。保守检测后只跳过受影响 run 并输出诊断，其他可支持 run 继续保护；没有临时加入多边形布尔引擎。
- 显隐后的无墨区段仍可有填充；不会为保护填充而复活隐藏线。

## 自动继承层序的独立修复

同一事务内，拓扑作者与外层提交可能先后调用自动图层传播。第二次必须识别已经符合当前父层序的继承结果，不能将其误存为新的局部排序覆盖。`automaticSnapshotEdits` 现在保持这种幂等性，并保留真正手动重排及已有明确覆盖。旧存档中的覆盖来源不可仅凭当前状态推断，因此不会加载时批量清掉。

# Basis cage scopes and temporary Recorder cages

A saved basis cage is an ordered field on the current Snapshot layer. Absent `strokeScope`, every current curve in its explicit `layerIds` receives the field, including later source curves. `strokeScope: {kind: 'continuous-strokes', curveIds: [...]}` instead records canonical provenance anchors. The existing Drawing `strokes()` topology resolves the current components containing those anchors. Cage bounds, point proximity and visible geometry never decide membership. Shared nodes connect strokes; cross-layer endpoint links remain independent authorities and require a coherent edit.

A source split replaces the old provenance identity with its children. Before deletion or local topology changes, the same resolver carries actual connected members into provenance. Consequently an appended continuation stays in the field after its original anchor is removed. Local exclusions retain absent provenance for restoration; actual source deletion prunes retired IDs through the existing source-reference remap. An empty stroke scope remains empty. Undo/Redo restores the operation and its provenance through the existing chronological project history.

A complete layer selection authors a whole-layer cage. A complete stroke selection authors a stroke cage even if it happens to include every currently visible curve. Reopening the last compatible cage edits its existing operation ID and fixed rest frame. New domains retain the existing authored order; a whole-layer field and a stroke field can coexist as distinct stages. Source ownership, snapshot-local controls, sparse post-domain corrections, locks and relation authority retain their existing write boundaries.

At each real Recorder basis, the Snapshot evaluates its own ordered fields and final controls. Recorder interpolation then mixes those evaluated controls through the existing basis/response path. It does not interpolate cage parameters or invent a field at an intermediate angle.

At an intermediate triangulated Recorder angle, the cage is a temporary Drawing tool. The shared Drawing deformation fitter produces desired controls; the existing grouped control-target transaction inverse-solves one atomic response edit. Only that response draft is saved. No cage domain, new real Snapshot, or persistent cage relationship is authored. A failed coordinate clears the entire pending gesture, including any earlier successful pointer preview. Basis endpoints remain unchanged, and onion previews use the same Recorder evaluation as the main canvas.

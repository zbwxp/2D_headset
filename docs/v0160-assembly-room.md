# V0.16.0 — 独立组装绘制间

本地版本，不发布网站。入口：顶部「菜单 · 文件与工作区 → 进入组装间」。

## 使用

1. 「载入绘制间快照」选择正面快照或当前绘制画布。复制到组装间，不改原画。
2. 左侧设置主轴姿态、定位面高度、定位点的平面 X/Z。主轴上方金色箭头表示正面；紫色线是主轴。定位面一直垂直于主轴，没有单独倾角。
3. 右侧选图层（也可在左侧「挂接图层」中选），选择一个语义定位点，点击「挂接到…」。绑定保留画面，无跳变。一层只对应一点，同一点可挂多个图层。右侧 Shift 连选或 Ctrl/Cmd 多选图层后，可一次挂接到同一点（例如左眼睑＋左眼内结构），一次撤销整批操作。左侧「此定位点已挂接」列出全部挂载图层，点击名称选层、单独解除挂接；各层保留独立偏移和原遮挡顺序。已有同点挂接不会被重复操作重置。
4. 拖动左侧 3D 预览或调整 Yaw / Pitch / Roll。点按三维姿态运动；默认图层只平移和等比缩放，始终朝向屏幕。顶部可打开「图层随主轴旋转」试验 3D 卡片效果，见下文。缩放以挂接时 100% 为基准。定位点深度不排序、不隐藏图层。
5. 可直接在任意姿态编辑曲线与 handle；编辑逆映射回独立原稿。背景仍由复制的绘制工具单独控制。
6. 图层偏移 X/Y 支持漫画式位置修正。组装快照保存当前画稿、主轴、平面、点、挂接和偏移；切换快照一并恢复。普通绘制间快照与录制间不受影响。
7. 删除点/面或解除挂接时，保留当前矢量画面。图层/曲线显隐、填充、组、显示区间和深度 offset 沿用原有行为。

本阶段不自动生成变形器，不把组装快照同步录制间，也不根据定位点深度改变遮挡。跨层端点联动和跨层共享填充/offset 边界不支持独立挂接；界面明确提示先解除跨层依赖或归入同层，避免相互冲突的变换。

## 图层随主轴旋转：3D 卡片对照开关

顶部「图层随主轴旋转」默认关闭。开启后，已挂接图层像正面朝向屏幕的纸片一样跟随主轴的 Yaw/Pitch/Roll，侧转变窄、俯仰缩短、歪头转动，并有卡片内部的远近透视；未挂接图层保持原位。所有图层的初始方向固定为正脸（0/0/0），不是打开开关那一刻的方向。转到背面显示卡片反面的镜像，不自动背面剔除；接近侧向时自然变窄。

这是可逆的显示预览：不烘焙图片、不改写正脸 Bézier 控制点，不增加快照或曲线。原有挂接位置校准、每层 offset、图层顺序和跨层 depth offset 都保留；深度不参与遮挡排序。已存在的线条笔触、填充、透明镂空和雾化跟随整张卡片投影。

预览时可继续旋转主轴、平移/缩放视口、移动背景、切换快照、切换图层/填充显隐。关闭开关后按原方式编辑曲线；主动选择曲线或绘图工具也会退出卡片预览，避免反解侧向压扁的卡片。开关可撤销，作为 `assembly.followAxisRotation` 随项目保存（旧文件缺省关闭）；不属于每个快照的 rig frame，切换快照保持这个对照模式。

实现：`domain/assembly/cards.ts` 推导卡片的完整平面单应变换，绕挂接点投影，几何与纸片三维投影一致。原 PaintScene 仍生成 SVG，每个原有绘制批次通过 `foreignObject` 中的 HTML `matrix3d` 合成，再回到扁平画家顺序。不能直接把 matrix3d 放到 SVG g 上（Chromium 会丢掉透视分量）。不使用贴图烘焙，不重复存储变形后的数据；浏览器负责最后显示合成。普通绘制间不改动。

## 轨迹预览与主轴视角 Slot（录制前准备）

- 3D 定位窗增加正脸与侧脸 ±90° 按钮，切换时把 Pitch/Roll 归零；主轴位置和相机距离保持当前值。
- 「主轴视角 Slot」默认 9 个空位，可继续新增、命名、覆盖和清空。只保存 Yaw/Pitch/Roll，随 JSON 保存且支持撤销；不保存或回退点 XZ、面 Y、挂接、图层或背景。重新载入绘制间画稿也保留这些视角书签。
- 显示的是当前构造的完整 Yaw 轨迹：固定当前 Pitch/Roll 与点面参数，使用实际 `worldPoint` 运算采样。3D 定位窗和画稿上的独立参考层使用同一套轨迹，仅选中点显示名称并高亮轨迹，可切换「所有定位点 / 仅选中点 / 隐藏轨迹」。轨迹没有编辑手柄，不可拖动，不写入存档。
- 定位面继续随主轴旋转。每条轨迹用 96 段显示，纯 Yaw 导航复用样本；不是逐帧追加的运动残影，也不是新增曲线资产。
- 图层/属性栏边缘的常驻按钮可以向右收起整个面板，再展开保留列表状态。空出的画布显示空间用于检查主轴与轨迹。

本轮没有加入角度关键帧录制或轨迹插值。当前修改点 XZ、面 Y 仍会修改全局构造；视角 slot 只是快速返回角度的书签。下一轮再设计各角度的定位修正和插值，不能把这些预览路径当成已录制轨迹。

## 参考图位置 Slot

在右侧参考图属性的「参考图位置 Slot」保存、命名和切换预设。默认提供 9 个空位，点击空位直接保存当前位置；点击已保存的 slot 一键恢复。使用「保存为新 Slot」可继续增加，不限 9 个。选择 slot 后可以改名、用当前位置覆盖，或清空。

slot 保存参考图的 X/Y、缩放、旋转和透明度，不保存视口平移、主轴姿态或画稿，不重复存储图片。锁定参考图仍允许明确点击 slot 切换，显隐和锁定本身保持不变。操作支持撤销/重做，随组装 JSON 及组装快照保存；更换或移除图片会使用新的参考图状态，原绘制间不受影响。

## 视口与三维定位参考

主轴、定位面和语义点属于独立的三维定位参考层，不属于二维画稿视口内容。

- 右键 / 中键 / 空格 / 抓手：照常平移二维视口，画稿、参考图及二维编辑辅助一起移动；三维定位参考保持原位。
- 滚轮 / Z / 底部缩放 / 适配：两者共用缩放比例与缩放中心，保留当前相对对齐；Esc 取消 Z 拖动会同时恢复两个视图。
- 调整主轴：使用左侧「主轴位置与透视」的 X/Y/Z。这才是修改模型位置，会记录撤销与快照。
- 平移视口不改模型、曲线坐标、背景偏移或已有挂接，不写入快照，也不占用撤销历史。挂接时按当前屏幕对齐位置换算图层缩放中心。

开发：`assemblyDrawing/session.ts` 的 `pan` / `rigPan` 是两个独立视图原点，`view.ts` 处理共同缩放和挂接坐标换算。仅组装间使用，普通绘制间交互不变。

## 开发边界

- `src/ui/assemblyDrawing/` 是绘制间编辑器的独立副本，包括工具交互、属性、图层、快照、局部会话、CSS 和偏好键。不得把组装实验改回 `src/ui/drawing/`。
- `src/domain/assembly/model.ts` 是主轴 / 平面 / 定位点 / 图层相似变换的数据和计算。
- 共用底层 Drawing Bézier/填充等几何函数，但不共用工作区 UI 状态。
- `project.assembly` 保存独立规范画稿与 rig；派生画面不重复入档。编辑器适配器反变换编辑坐标，保证视图与拾取/编辑一致。
- 组装快照保存规范坐标和各自 rig frame，显示时派生姿态；未挂接图层保持不动。引用背景仍用快照图片池。
- `scale = cameraDistance / max(0.5, cameraDistance - z)`，以绑定时 scale 归一化。缩放绕绑定 anchor，平移为定位点投影位移加手动偏移。所有曲线控制点、隐藏几何、线宽、端点笔触和雾化距离一致缩放；不改变曲线拓扑、图层顺序或 depth offset。
- 主轴旋转使用 `Rz(Roll) × Rx(Pitch) × Ry(Yaw)`（列向量右侧先作用）。Pitch/Roll 决定主轴方向，Yaw 在该方向上自转；固定 Pitch/Roll 改 Yaw 不会让主轴摆动。轨迹是定位面内以主轴交点为圆心、半径 `hypot(x,z)` 的圆；不要改回绕世界 Y 采样。二维投影后不要求视觉上仍为直角。修正前倾斜姿态绕错轴，修正后相同角度数值的倾斜姿态显示会改变；正面及纯 Yaw 不变。
- 快照不是已接入录制的承诺；后续单独设计变形器复用及录制集成。

## 图层四角透视：可复用、保留原稿

在图层栏选中一个图层，点击组装间顶部「图层四角透视」，拖动橙色框的四个角。框覆盖整层几何，包含隐藏的线与填充边界；线、填充、显示区间和端点笔触按同一透视关系显示。锁定对象需先解锁。交叉或退化的四边形会保留拖动中的最后有效形状，Esc 取消本次拖动；一次拖动只记一次撤销。

- 「启用」关闭效果但保留四角；「重置透视」回到原矩形。
- 「复制变形」→选择另一图层→「套用变形」，按目标原稿范围套用同一比例的四角关系，不复制线稿。已有变形器保留其基准范围。
- 「编辑原线稿」暂时回到原稿（随轴卡片也退出），修改端点/handle 后点「查看变形」。原稿编辑不清除参数，原框也不会随新几何自动重算。
- 「收起四角框」只隐藏控件，效果继续存在。原侧栏的「四角变形」仍是修改所选曲线的旧工具；需要可复用参数时用顶部「图层四角透视」。
- 参数进入组装快照与 JSON，支持撤销/重做。恢复旧的无变形器快照会清除当前变形器。载入另一份绘制间画稿会清除旧挂接与变形器。

数据为 `AssemblyFrame.perspectives[]`：每层一个固定 canonical `source` 矩形、四个归一化 `quad` 角及 `enabled`。保存源 Bézier，不存变形后的重复曲线；快照存取直接使用 canonical 原稿，避免无编辑时反复正反投影带来的浮点漂移。

显示使用平面单应矩阵：先图层手动透视，再定位平移/等比缩放，最后可选随轴卡片投影。四角编辑在最终屏幕坐标反解到 canonical 控制框，因此侧转视角也可拖四角；接近不可逆的侧立位置需转回一些角度。归属、图层顺序、跨层 depth offset 均不改变。此段为四角原型的历史实现；当前已使用下文的矢量中心线投影与固定线宽渲染。

这套参数目前保存在组装快照，尚未接入角度插值/录制，也不反推出定位点、主轴角度或深度。任意四角透视并不等于固定相机下同一张刚性卡片的纯旋转。

## 定位姿态录制（当前已实现）

这部分取代上文“仅做录制准备”的状态。入口在左侧 3D 预览下方「定位姿态录制」，与“主轴视角 Slot”分开。Slot 仍只记角度；定位录制建立可以连续求值的运动参数。

1. 在正面完成基础点面布局和图层挂接，点击「保存当前角度定位」。首次保存开启录制预览，并冻结一份轻量的定位基准。
2. 将 Yaw 调到 30°/60° 等目标角度，调整原有的「点 X · 平面左右」「点 Z · 平面前后」「平面轴向高度」，以及挂接层的「图层偏移 X/Y」。数值即时预览，写入该角度草稿，原基础构造不变。
3. 点击「保存当前角度定位」或「更新此角度定位」。同一 Yaw/Pitch 覆盖同一个关键帧，可以命名；拖角度在保存点之间预览插值。列表可直接回到某个角度，单帧可删除；上述操作均支持撤销。
4. 草稿按角度保存，切角度和保存/加载 JSON 不丢失。回到原角度继续修改或「撤回定位草稿」。轨迹显示已保存的数据，当前点显示草稿；保存后轨迹更新。
5. 完整环绕转头时打开「整圈循环插值」。默认关闭：只插值已覆盖的连续角度区间，最大空白扇区不推测新姿态，使用最近端的局部定位继续随轴旋转。170° 到 −170° 可自然跨越背面接缝；±180° 是同一角度，不重复建帧。
6. 可在不同 Pitch 行录制。每行先按 Yaw 求值，再在相邻 Pitch 行平滑混合；Pitch 范围外使用最近一行并提示范围外。Roll 作为独立整体旋转，不建立重复的定位关键帧。主轴整体 XYZ、相机距离仍是全局构造设置。

「使用定位录制」关闭后回到基础构造，已有关键帧和草稿保留；关闭时才能增删定位点/面。普通点面改名保持 ID，不影响对应关系。新增点在缺少记录时使用自身基础坐标；删除点的旧记录忽略。每个定位面的 Y 仍由该面所有定位点共享，保持自由度限制。

录制值为点的**主轴局部 X/Z**、面的局部 Y，以及独立图层偏移。先用 smoothstep 权重混合局部值，再执行实际 `Rz × Rx × Ry` 与相机投影；没有修正的点仍走原有圆周，不能把屏幕端点连成直线来代替运动。定位带来的深度等比缩放、原遮挡顺序与 depth offset 保留。既有四角参数不随本次录制更改，源 Bézier/显隐/显示区间不录入定位通道。未实现弯曲通道、透视角度插值或同步旧录制间。

持久化为 `assembly.placement`：`base`、`keys`、按角度存放的 `drafts` 及 enabled/loop。每帧只存小型数字映射，绝不复制线稿/图片。角度规范到 0.001°，同角度唯一；稳定定位点/面/图层 ID 对应。加载旧文档没有该字段时保持旧行为。

全量组装快照仍是备份：保存时捕获当前求值后的定位与原稿，快照内不复制整套录制轨道；恢复全量快照会暂停定位录制预览以忠实还原备份，同时保留全局录制轨道。需要继续录制可重新打开「使用定位录制」。「从组装快照录入定位」按快照角度提取匹配 ID 的定位数值，不替换原稿、透视或挂接校准。重新载入另一份绘制间画稿会保留定位轨道，图层需重新挂接，便于套用另一套资产。

测试：`src/tests/assembly/placement.test.ts`、`tests/e2e/assembly-placement.spec.ts`。轨迹、卡片、图层跟随与编辑器适配器都通过 `resolvePlacement` 使用同一求值结果；不要分别做三套插值。新增会影响定位的状态时须检查几何与轨迹缓存依赖。

### 检查已录制轨迹

左侧「Yaw 轨迹」同时控制 3D 示意与绘制画布中的轨迹。默认不显示轨迹，点击 3D 定位点或使用「检查定位点」「语义定位点」选择后，只显示该点的轨迹与角度标签。清空选择可隐藏；需要整体对照时仍可手动选择「所有定位点」。空心点表示已保存角度，没有保存的草稿不进入轨迹。

检查轨迹时固定其来源 Pitch 行，转动主轴 Yaw/Pitch/Roll 不会切换来源或清除轨迹。采样用固定来源的定位数值，显示用当前主轴的 Pitch/Roll 倾斜，可拖到俯视检查同一条轨迹；Yaw 继续沿轨迹扫角，不重复旋转整条路径。多行录制时，可通过「轨迹俯仰」选择检查哪一行。来源选择只是临时辅助显示，不写入 JSON、不改变关键帧，也不改变图层自身的实时姿态求值。

「显示范围」默认选择「已录制角度段」，即去掉相邻记录间最大的空白扇区，便于检查局部录制。它只控制辅助显示，不修改存档的「整圈循环插值」。选择「全部插值范围」可检查循环补全的其余部分。采样仍使用真实的 `resolvePlacement` → `worldPoint` → 投影，不重新拟合平滑曲线；关键角度精确采样，相邻角度间补采样。因此看到的鼓出和折返是实际的已保存运动。

## 图层四角变形与插值

四角透视按图层记录 Yaw/Pitch 关键帧，源范围固定在 `perspectives`，角度数据保存在 `assembly.deformRecording`。当前保存、切换、删除等操作统一使用下文的角度姿态界面；旧独立的定位与透视录制面板已撤下。

`placement.angleWeights` 提供邻角查找、smoothstep、Pitch 分行与 ±180° 接缝规则。四角变形对规范化单应变换进行分解，分别插值位置、最短旋转、对数尺度、剪切及透视分母，避免直接平均角点导致大角度旋转中途塌缩。禁用形态作为未变形矩形参与过渡；极端无效参数使用有效关键形态保护渲染。

原始 Bézier 不会被四角操作改写，透视由下文的矢量投影绘制呈现。计算顺序固定：原稿上的手动透视 → 定位平移与远近缩放 → 可选的随轴卡片旋转；阶段按钮选择累计显示的效果，点击先后不会改变计算顺序。四边弯曲现已实现，见文末。

## 统一角度姿态（当前交互，取代上文各自的录制面板）

组装间现在使用一套角度姿态入口。顶部「原稿 / 定位 / 透视 / 弯曲」是累积应用的预览阶段；「显示区间」单独开闭，在任意阶段可用。弯曲阶段在定位和透视的基础上应用四边曲线场。原稿基准可以是任意 Yaw/Pitch，在侧面开始绘制时，在「姿态记录 → 原稿基准角度」设定；录制其他角度后不直接改基准。

日常步骤：选择角度 → 调定位点、图层四角、笔画区间 → 顶部「保存此姿态 / 更新此姿态」。该按钮保存当前角度所有修改过的项目，不受当前图层选择影响。换角度保留草稿，草稿只在所属角度预览，保存后才参与插值。角度列表显示 `*` 表示待保存。撤回草稿、关键帧删除、原稿修改都支持 Undo/Redo，草稿随 JSON 保存。

「姿态记录」内展示所选图层的定位偏移、透视、弯曲、区间状态，并可逐项删除或删除此图层在当前角度的记录。未录项目用自身轨道的插值，不自动在别的图层或通道插入关键帧。定位点与平面是共享记录，在单独的「共享定位点与平面」折叠区删除，删除图层记录不会删掉其他图层依赖的定位轨迹。「固定当前值」的 + 按钮仅固定指定图层的指定通道。

「编辑原稿」修改共用资产；完成后返回姿态预览。钢笔、椭圆等绘制工具进入原稿编辑。在姿态编辑中点击左侧四角工具，打开的是可复用的图层四角透视，不改原始 Bézier。端点/控制柄直接修改需要明确进入原稿编辑。显示区间属性与端点拖动在定位、透视预览中均可使用。透视下，区间端点通过逆投影沿原曲线滑动，填充不被区间裁剪。

旧完整快照保留在「工具选项 → 历史完整快照 · 导入与恢复」，供恢复原稿；其恢复进入原稿编辑，完成后重新应用姿态记录。日常角度录制无需旧录制间，也不再操作独立的定位/透视保存按钮。

### 数据与迁移

- `AssemblyDocument.timeline` 保存基准角度、阶段/区间预览选择、统一循环设置、姿态名称，以及图层下的区间关键帧；不复制完整画稿或图片。
- 现有 `placement`、`deformRecording` 数据保留。进入组装间时按角度汇总为一份列表，旧定位值不重拟合。定位改为稀疏字段插值，新角度只修改一个点时不会重启其他点的插值节奏。
- 四角关键帧第一次创建时补的是当前原稿基准角度，不固定补 0°。各图层的源控制框仍固定，原曲线不受四角操作修改。
- 区间在图层内按笔画记录覆盖对象 (`IntervalKey.curveIds`)；在同一层编辑第二条笔画也不会向第一条笔画误加关键帧。复用 Recording 的区间对应、闭环接缝、显/断线覆盖与收尖后断开算法。临时 pinch 强度在定位缩放后继续传递，不写 JSON。
- 预览开关只决定显示哪些效果；关闭区间后保存其他内容，不把关闭状态当作清除所有区间。区间编辑数据与画布开关分开。
- 原稿中的笔画跨层移动时，区间关键帧随稳定曲线 ID 迁移；删除曲线后清理对应引用。透视与区间分别删除，图层顺序/深度 offset 仍负责遮挡。


## 四边 Bézier 弯曲与固定线宽（2026-09-29）

选择图层 → 顶部「弯曲」→「四边弯曲」。四角框共用已有透视的固定源矩形，四条边各有两个控制柄，另有四个边中点快捷拖柄。圆形柄细调边界；菱形边中点同时移动该边的两个控制柄；方形角继续编辑透视。支持 Esc 取消、一次拖动一次 Undo；折叠/压扁的候选区域保留上一个有效形态并提示。

算法为 **Coons patch（四边界混合插值）**。四条归一化三次 Bézier 的位移共同决定内部点，沿相对边线性混合。它准确插值四条边界，不是逐点选择最近边；邻近边影响更大且没有最近边切换的折痕。四角约束由共享端点满足。四边保持直线时，弯曲严格为恒等映射，原四角透视不变。当前只有边界自由度；保持四边完全不动而局部捏内部的需求，需要后续增加内部控件。

固定几何计算顺序：原稿坐标归一化 → Coons 弯曲 → 四角单应透视 → 定位/等比深度缩放 → 可选随轴 3D 卡片 → 视口。顶部按钮表示累计启用哪些通道，点击次序不会改变计算。显示区间先在原笔画材料坐标中求值，再跟随中心线变形，填充不受区间裁剪。投影区间抓手使用逆单应矩阵 + 数值反解 Coons 回到源曲线定位；不存在对原曲线的破坏性修改。

**线宽不受上述任何变形或深度缩放影响**。先投影中心线，再使用原线宽生成 stroke 或收尖轮廓，尖点连接也按投影后的切线与原线宽重算。视口放大仍正常放大整幅画。曲线、填充在绘制时自适应拟合为临时多段 Bézier，普通精度约 0.15 屏幕像素，源 Curve ID 和存档仍维持原有拓扑。保存文件不增加采样点或栅格图。组装间已撤下旧 CSS matrix3d 线稿缩放路径。

`timeline.bends` 为稀疏的图层轨道，每个 key/draft 只保存 Yaw/Pitch、4×2 个归一化控制柄与 enabled。第一次编辑补当前 base 角度的直边基准，其他角度草稿只在该角度显示；顶部「保存此姿态」一次提交修改过的通道。不同角度按统一 Yaw/Pitch 权重插值控制柄；无记录角度不自动建帧。异常插值形态会提示并沿用邻近有效关键形态。支持逐层/逐项删帧、整圈插值、JSON、复制曲边到另一图层（按其源矩形适配）。图层顺序和深度 offset 继续决定遮挡。

参考：
- Coons patch：C. L. Bajaj, *Splines and Geometric Modeling*, https://www.csun.edu/~ctoth/Handbook/chap56.pdf 。
- Live2D Warp Deformer 的控制分割/变换分割说明：https://docs.live2d.com/en/cubism-editor-manual/making-and-placement-of-warp-deformer/ 。借鉴少量 Bézier 控件驱动区域的交互；不声称使用 Live2D 未公开的内部算法。

## 统一区域变形器与单线微调（2026-09-29，后续更新）

以上分开的「透视／弯曲」入口现已合并为 **区域变形**。同一个框内拖四角调透视、拖边中点或八个控制柄调曲边。复制、套用、重置、启停同时处理两项；原透视和弯曲关键帧仍分开存储并独立插值，旧存档保留。图层姿态面板将两项合并显示与删除。

顶部累计阶段：**原稿 → 定位 → 区域变形 → 单线微调**。显示区间仍是独立预览开关。未做微调的已录制图层姿态进入「单线微调」保持区域变形线形，紫色提示条和控件说明正在改当前角度；「编辑原稿」按钮才是共用资产编辑入口。属性面板在姿态模式下隐藏原稿坐标、原稿几何变换等控件，避免误认。

- **V**：选择整笔／组合，显示显示区间 A/B 抓手。Shift 或 Ctrl/Cmd 增减选择。
- **A**：选择原始单段，显示完整的原曲线结构、端点、共享接头及切线柄；隐藏显示区间抓手。即使该段有断线区间，结构仍完整展示。坐标已应用当前姿态的区域变形，不会跳回正面。
- 在「区域变形」阶段，A 的蓝色控件仅用于查看；进入「单线微调」后变为紫色，可拖动。V/A 或改选列表成员会收起大变形框。
- 微调完成后点击同一个「更新此姿态」。支持草稿跨角度保留、每次拖动一次 Undo/Redo、Esc 取消、JSON 存取及删除当前曲线或图层的角度微调。删除共享接头修正会同步移除相连端点的对应记录。

微调是严格的后置几何层：`result(t) = F(sourceBezier(t)) + deltaBezier(t)`。F 包含现有定位、透视、曲边和可选 3D 卡片。delta 的四个向量按首次建立轨道时的图层源框尺寸归一化；零修正严格保持现有 F，无须把非线性结果先强制塞回一条三次曲线。显示的切线柄使用 F 在原端点的导数再加 delta 控制向量，因此是最终形态的端点切线，不是简单投影原控制柄。实际曲线仍可自适应生成多段临时渲染曲线，存档不增加段数。

`timeline.refinements` 按稳定 Curve ID 保存稀疏 key/draft（角度、四个修正向量、归一化 size、controls 覆盖列表）。**图层姿态是零偏移边界**：这个图层在某角度已有定位、区域变形、区间或微调记录时，没有明确微调的曲线/控制量为 0；两个图层姿态之间才插值两端偏移。controls 标记实际编辑过的控制量，缺失项在该姿态为零。共享端点使用相同边界，避免只有一侧改变插值节奏。绑定端点一起平移，对应相邻柄随端点平移；SMOOTH 接笔的对侧柄在编辑时保持反向共线。

绘制派生几何保留运行时曲线来源与参数范围，裁切、反转、圆弧接头、填充和区间抓手共享修正映射。区间拖动在最终投影曲线上求最近位置，不需要反解微调。原笔触宽度在所有几何阶段之后构建，仍不随透视/缩放改变；视口缩放正常。圆弧桥使用两侧修正的平滑混合保持连接。

微调服务于对应语义曲线的细节修正；它不等于可自动匹配任意不同拓扑资产。共用区域变形器仍是主要的资产复用方式。原稿拓扑增删需要保留稳定 Curve ID；删除原曲线会清理其微调轨道。

## 主轴与视口联动锁（2026-09-29）

首次使用「主轴与视口」锁为关闭；以后恢复上次状态。先独立平移画布完成对齐，再锁定；右键、中键、空格和抓手平移时主轴参考与图层/背景一起移动，保留锁定时的相对位置。开关本身不跳位。缩放、Z 工具及适配始终共享缩放基准，避免对齐漂移。解锁后平移再次只移动画布内容。

## 区间随角度启停（2026-09-29）

属性 → 显示区间 → 每个区间的「启用此区间」。显线与断线都能独立暂停，位置、端点笔触和稳定 ID 保留；暂停时该区间不参与裁线，其他区间继续生效。所有区间关闭时整笔显示。关闭的区间卡片为虚线边框，V 下的 A/B 标记淡化但仍可编辑；填充不受影响。

在组装间姿态模式，开关与区间位置一起记入 `timeline.intervals`，点击「更新此姿态」保存。例：基准 0° 关闭，30° 开启，60° 关闭：`[0,30)` 关闭，`[30,60)` 开启，到 60° 关闭。从基准往负 Yaw 录制也按离基准由近到远保持前一状态；基准不必是正脸。区间的位置和笔触仍连续插值，只有布尔开关为保持型切换。俯仰采用同样的基准向外保持规则，在相邻俯仰行中先取靠近基准的行，再选该行的 Yaw 状态；不依赖鼠标转动方向或播放历史。未覆盖角度沿用现有角度采样的最近记录，整圈模式支持 ±180° 接缝。

顶部「显示区间」仍只是全局预览，不录制启停关键帧。「编辑原稿」中的开关修改的是共用资产。绘制间同步提供静态启停，并随绘制快照和 JSON 保存。

数据为 `DisplayInterval.enabled?: boolean`，旧存档缺省启用。只有显式启停的区间使用上述状态采样；旧的区间新增、删除与笔触渐断插值保持原有逻辑。显式开关不应被混合 SHOW/HIDE 的覆盖范围归一化抹掉。组装间将保持状态的样本索引传给共享 `blendPoseIntervals`，几何采样权重不变；旧录制间没有基准向外状态轨道，读取这种新字段时沿用权重最大的快照状态。

### 微调从零开始（2026-09-29）

微调是区域变形之后的 offset。默认 0，不沿用邻近姿态的修正。规则按图层生效：本层的定位记录（包括绑定定位点、所属平面的记录）、透视、曲边、显示区间或微调关键帧共同形成姿态边界，base 也是边界。边界处未手调的曲线/控制量隐式为 0，无需在 JSON 给每条线补零关键帧。别的图层的记录和单独的姿态名称不形成边界。

- 已有手调的姿态保持自己的 offset；新姿态草稿从 0 开始。
- 转动 yaw/pitch 只是求值，中间角度继续插值，不自动建帧。
- 在未录制角度明确进入「单线微调」，会为所选图层已有修正轨道建立零值草稿；也可以直接开始拖动。保存后成为新边界，撤回草稿恢复插值。
- 删除微调后，如果本层在该角度仍有其他姿态记录，则恢复 offset 0；删除整层该角度记录后，才由邻近姿态重新插值。
- 状态「未微调 · 偏移 0」区别于「插值」。编辑共用原稿仍必须进入「编辑原稿」。

`refinementFrames` 在运行时按图层汇集边界，WeakMap 缓存不写入存档；原有 `controls`、偏移数值与 Curve ID 保留。实际提供的组装存档在 −45° 没有微调，四条下颌/封口线的最终路径与区域变形路径差值均为 0，检查结果在 `artifacts/assembly/refinement-zero-audit.json`。

### 稳定显线/断线区间的身份（2026-09-29）

60°/90° 下颌案例：两端各有同 ID 的一个 SHOW 和一个 HIDE，旧插值仍将混合模式转换为 full SHOW＋临时 HIDE 覆盖，造成原来的移动缺口失去身份。两帧缺口重叠很少时被误判为独立的消失/出现区间，中间出现第 3、4 组并改变缺口运动。

`alignPoseIntervalDrawings` 现在先匹配重定位后的原始区间（稳定 ID 优先；旧编号按同模式、不歧义的重叠匹配），再比较匹配后的 ID＋模式集合，不依赖数组顺序。能对应同一套区间的混合 SHOW/HIDE 保持原始通道，直接插值位置与端点笔触。只有不同表达方式（例如 HIDE 中段与 SHOW 两侧）的对应才需要覆盖归一化；显式启停与新缺口收尖过渡照旧。原存档无需迁移，读取与预览不改变关键帧。回归数据 `src/tests/fixtures/jaw-60-90-intervals.json` 只包含必要的面部几何与两角度区间，测试包含 69°、端点临界角、保存/读取以及界面两卡片、四抓手。

旧编号补充（2026-09-30）：30°/45° 的两组区间分别使用原 ID 与旧版 coverage 派生 ID。只在 ID 完全相等时跳过归一化仍会使 37° 多出第三组。对应匹配必须先于覆盖转换，而非先转换再匹配。匹配仍是保守的：不同模式、同帧共存、重叠过小或歧义的区间不会强行合并。`jaw-all-angle-intervals.json` 保留该存档全部七个面部区间关键帧；每段扫描 101 个位置，涵盖旧 ID、显式关闭、跨闭环原点以及中间角度编辑保存。-20° 原本有三条（其中一条关闭），这是真实源记录，应保留；-30° 至 -90° 的两组不会因插值增殖。

## 刷新恢复工作间（2026-09-30）

浏览器按工程 `meta.createdAt` 在 `localStorage` 的 `contour.workspace-session.v1.<createdAt>` 保存轻量界面状态：当前工作间、绘制/组装/录制各自的平移缩放、组装 `rigPan` 与联动锁、当前工具与选择、图层树折叠/填充预览、侧栏显隐及比例、3D 定位栏显隐与选中定位点/轨迹查看选项。原有工具栏图钉及属性面板折叠继续使用 `contour.panel-layout.v1`。

初始化在 React 挂载前恢复，不能再无条件切回绘制间。两个视口原点用绝对值同时恢复，不经过锁定平移的增量计算；切换工作间不能清空恢复的选择。只有该工程从未保存界面状态时才初始化，切换不同工程各自记忆。180ms 合并写入，页面隐藏/刷新时立即保存最后状态，不依赖定时器完成。

界面状态不进入 JSON、角度快照、Undo 或几何计算。主轴实际姿态、参考图变换、录制关键帧仍由工程 JSON/自动保存负责。此界面记忆限同一浏览器、同一站点地址；`localhost` 与 `127.0.0.1`（及不同端口）是不同存储空间。损坏/禁止本地存储时仍能打开工程；不恢复未完成拖拽、弹窗或剪贴板。测试：`workspace-session.test.ts` 与 `workspace-session.spec.ts`。

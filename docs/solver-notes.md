# 曲面求解实现与限制

## 坐标与拓扑

X 为左右，Y 为上下，Z 为正面。椭球半轴为 (0.86, 1.22, 0.94)，32 经线、32 纬度区间、两个唯一极点。使用 994 个顶点和 1,984 个外向三角面；每条边关联两个面，Euler characteristic 为 2。

正交视角以 camera.position - camera.target 为 forward，right = normalize(up × forward)，vertical = forward × right。投影为点到 camera.target 的偏移与 right / vertical 的点积。SVG 只在显示时翻转 Y 并乘 160；缩放平移不写入约束坐标。每个视角独立保存 canvas.zoom / canvas.pan，随项目 JSON 和本机自动保存持久化。

固定 160 px / 单位作为验收参考分辨率。因此 diagnostics 中的 px 与缩放百分比、设备像素比无关。

## 曲线对应

Semantic rings 使用稳定的 vertexId 与 u 参数。闭合 polyline 的控制点保存独立递增参数，增加控制点不会改变现有语义采样的参数。控制点之间线性插值。控制点拖动后重建全部密集样本。水平正交视角下，语义环使用基底投影横坐标在可见控制点间分段线性插值，前后半环使用同一对应规则，消除隐藏样本保留的波峰。俯仰视角保留基底相机投影的弧度。轮廓使用闭合 Catmull–Rom 插值，密集样本不再具有独立自由度。正面、俯仰视图在对称模式下同步镜像目标。

Silhouette 使用相邻面朝向相机符号不同的网格边组成轮廓，每个非线性外迭代重新提取；按有向边追踪闭环，切线附近使用法线相对容差；以投影面积选择外边界。不会将未闭合路径强行首尾连接。简并失败时回退到投影凸包。投影样本每轮匹配目标 polyline 最近点。诊断额外测量目标到当前轮廓的逆向距离，以免突出目标没有对应样本时静默低报误差。

此近似不适合分叉、多孔、复杂遮挡轮廓；目标曲线自交不保证有合理解。对轮廓拓扑剧烈变化，UI 显示残差而不宣称成功。

## 最小二乘

未知是当前顶点坐标。所有方程按行存储稀疏系数，不构建稠密 3N × 3N 矩阵。对称模式将镜像顶点的 X 自由度共用且符号相反，Y/Z 自由度共用，正中线 X 固定为零。这是精确降维，而不是求解后再平均的近似。

目标能量：

```
E = sum(w_view * |P X - target|²)
  + fairness * |L X - L X_base|²
  + 0.08 * sum_anchor |X_anchor - X_base_anchor|²
  + 1000 * |centroid(X) - centroid(X_base)|²
  + temporal * |X - X_previous|²
```

L 是均匀邻接平均 Laplacian。该实现采用档案允许的保形形式 A（保形差分坐标），未叠加会导致收缩的纯 L X 项。时间稳定项 preview 使用设置值的 3 倍。对称能量是独立诊断，默认由降维严格为零。

权重：locked=100、strong=20、weak=2、guide=0。未被用户编辑的弱曲线是系统预测，不是静止观测：不加入求解系统，求解后跟随当前曲面重投影。手工设置的 weak 参与求解。锁定视角时保存其所有自动目标的当前投影，后续作为高权重观测；禁用约束仍不参与。

使用 Jacobi 预条件共轭梯度解正规方程。preview 外迭代 2 次、每次最多 30 CG 步；refine 外迭代 5 次、每次最多 160 CG 步。界面显示实际 CG 总迭代数（诊断对象）和实际运行时间，不是模拟计时。

一次提交的最大顶点移动限制为 0.12（头高 2.44 的 4.92%），其余移动在后续编辑/精细求解中收敛。能量在限制后的解重新测量。所有结果必须为有限数，否则拒绝替换曲面并提示错误。

## 交互调度与持久化

Worker 每次处理一个快照；忙碌时合并中间拖动，只保留最新请求。松手的 refine 优先于 preview。每次形体修改增加 revision，旧版本结果不会覆盖新编辑。撤销/重做/载入会终止旧 Worker，下一次求解按需重建。拖动起点保存一次历史，不把每个鼠标事件计入历史。

JSON 包含 surface、base / previous vertices、faces、normals、镜像对应、锚点、semantic model、各视图约束与求解设置。撤销历史是运行期状态，不写进 JSON 以避免单个项目指数膨胀。载入后重新计算法线并校验索引、有限坐标、参数顺序、相机基底和实体引用。

OBJ 输出 994 个顶点、单位顶点法线和三角索引，使用右手坐标；保留原有面绕序。V0 不做任意编辑后的自交修复或动画拓扑优化。

## 诊断

- enabled authored / locked constraints 的 RMS、最大误差与冲突比。
- 每视图 RMS 按样本数量加权合并；guide / disabled 不计入。
- locked：RMS ≤ 2 px、max ≤ 6 px；其他：4 / 12 px。任何单项超限均告警。
- 曲面中心漂移相对基底超过头高 0.5% 告警。
- 上部区域相邻顶点法线平均夹角与 P95；排除 Y ≤ -0.65 的下颌/下巴区。平均 >12° 或 P95 >35° 告警。这是光顺近似指标，不是面法线角或曲率精确值。
- 3D curvature 显示细分检查网格上离散 Laplacian 位移的颜色映射。

## 定位点与历史更新

定位点使用 `curve.handles` 引用曲线的密集采样索引；外轮廓按语义高度两侧及层间中点取样，另保留头顶与底部，正面默认 28 个。语义曲线通常显示两端与中间 3 点。拖动仅改变可见控制点，再重建密集采样。旧 JSON 自动补齐 handles、参考图锁状态，并将旧语义目标升级到 semantic-linear-v1；控制点、照片和已保存网格保留，隐藏起伏会被移除。

历史容量为 100，使用不可变项目快照的结构共享，避免每个历史节点再次深拷贝照片与几何。照片数据不发送给求解 Worker；仅保存在视角状态和项目文件中。

正中线为 33 个固定顶点构成的开放前侧经线（X=0、基底 Z≥0），不包含后侧经线。其所有视角约束均为 guide，保持只读，始终显示。旧闭合正中线加载时升级为前半条，参数重新归一化到 0..1。

# V0 验收记录

日期：2026-09-11。环境：本机 macOS、Node.js 24、Google Chrome、1440 × 1000 桌面视口与 390 × 844 手机视口。

## 验证结果

- TypeScript 与 Vite 生产构建通过，Worker 单独打包。
- 10 项几何/曲线/序列化/求解测试通过。
- 6 项 Playwright 测试通过，含完整工作流、文件下载和再载入、独立缩放、过期 Worker 结果、性能采样、六张截图回归、可选代理接口。
- OBJ 用独立 Three.js OBJLoader 重新解析，顶点/法线/面数量正确，包围盒与原模型一致。
- 依赖审计：Vitest 更新至 4.1.11 后报告 0 个已知漏洞。

## 数值测试：正面下颌 → 锁定正面 → 侧面颅顶

正面下颌宽度增加 12%、下移 0.055 单位，然后锁定整个正面。侧面颅顶深度扩展 8%。下表来自 `src/tests/solver.test.ts` 的实际结果；运行耗时随机器负载变化。

| 指标                   |                          实测 |         档案目标 |
| ---------------------- | ----------------------------: | ---------------: |
| 锁定正面的最差约束 RMS |                      0.803 px |           ≤ 2 px |
| 锁定正面的最大投影误差 |                      5.388 px |           ≤ 6 px |
| 侧面颅顶 RMS           |                      0.039 px |           ≤ 4 px |
| 曲面中心偏移           | 0.000183 单位，约头高 0.0075% |           ≤ 0.5% |
| 平均相邻顶点法线夹角   |                         8.17° |            ≤ 12° |
| P95 相邻顶点法线夹角   |                        12.40° |            ≤ 35° |
| 对称能量               |                        数值零 | 镜像距离满足阈值 |
| 精细求解               |                   约 63–68 ms |         ≤ 500 ms |

同时覆盖默认形体不漂移、轮廓拉宽、冲突的 locked 目标产生告警、禁用与 guide 不参与、preview 单次位移 ≤ 0.12。对不可兼容的目标没有隐藏残差。

## 浏览器输入与渲染采样

真实鼠标在正面下颌控制点上产生 20 次拖动事件。在原始 pointermove 事件到目标 SVG 路径 DOM 更新间计时，使用 requestAnimationFrame 记录同一段时间的帧间隔。该指标是输入到 DOM 更新，不能等同硬件显示器的实际像素呈现延迟。

缓存重复几何投影后、清空测试转译缓存的最终回归测量：

| 指标               |                  实测 |
| ------------------ | --------------------: |
| 输入到路径更新平均 |               5.33 ms |
| 输入到路径更新 P95 |              13.20 ms |
| 平均帧间隔         | 16.58 ms（约 60 fps） |
| 松手精细求解       |               31.3 ms |
| 本场景中心漂移     |         0.000046 单位 |

不会把此机器单次结果当作跨设备性能保证。完整测试并行构建或系统繁忙时耗时可能上升。长期运行的大型项目或极端约束仍需要进一步性能测试。

## 浏览器操作覆盖

- 启动后可见非空 WebGL 曲面与二维可拖动曲线。
- 拖动下颌改变 target 数据并触发真实求解。
- 锁定正面后侧面编辑不改写正面 authored 目标。
- 线框、法线、曲率近似、语义线和偏差显示切换。
- 控制点增加、删除；锁定或禁用时阻止编辑。
- 新建后撤销恢复旧项目，重做恢复新建状态。
- JSON 下载/载入的曲面、视角锁和目标状态保留；刷新恢复本机自动保存。
- 错误 JSON 被拒绝，当前编辑器仍可用。
- 各视角 zoom / pan 独立，切换后恢复。
- 在 Worker 忙碌时撤销，等待后旧结果不会覆盖恢复的目标。
- 窄屏页面无横向溢出。

本轮直接查看了默认桌面、编辑并锁定正面、手机纵向页面等截图。可见居中的连续椭球头部、不同颜色语义线、正确小视图；未见明显孔洞、尖刺和破面。目标与投影分别为浅绿色实线和蓝色虚线。已修复小视图锁图标被通用 SVG 样式放大的问题。截图是视觉检查，不代替数值验收。

WebMCP 通过注入实验 API 的兼容测试桩验证了工具注册、合法调用、可见状态更新与非法输入拒绝。当前环境未验证浏览器原生 WebMCP 实现，因此不宣称原生兼容性认证。

## 已知限制

- 锁定使用高权重而非绝对不动，不兼容约束会告警。
- 轮廓对应是迭代的最近点近似；大幅凹陷或自交没有完整鲁棒性保证。
- 基线形状与常规变形通过了正常数值阈值；没有对任意人为输入保证无自交。
- 法线夹角与曲率热图均为离散近似，检查网格细分不提供动画拓扑。
- 字体与 GPU 差异可能影响跨设备像素回归；应在统一浏览器和平台检查基线。

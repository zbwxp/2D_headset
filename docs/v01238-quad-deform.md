# V0.12.38 — Drawing Room 四角变形

## 使用

1. 在右侧点击图层名称，选中完整图层；也可以选择笔画、组合或多条曲线。
2. 点击左侧「四角变形」，拖动紫色框的四个角。网格表示透视方向。
3. 可以连续调整多个角。每次松开鼠标是一笔 Undo；Esc 取消当前尚未松开的拖动。
4. 「完成」返回整笔选择，继续平移、缩放、旋转；A 切换到端点和 handle 微调。
5. 「重置变形框」只把控制框重新包住当前结果，不恢复原始几何。恢复几何请撤销。

完整图层或完整组合的变换包含隐藏成员，且不改变它们的显示状态。高光边界可以继续隐藏，填充仍随边界变形。锁定成员阻止整个操作，不会被静默跳过。普通 V 平移、缩放和旋转也使用这个规则。只选择隐藏的局部成员仍受原有编辑限制。

## 数据与约束

- 存储结果仍是原来的普通 cubic Bézier；不转位图、不增加线段、不重建 ID。
- 保留节点绑定、接笔关系、组合/图层归属、填充引用、深度偏移和列表顺序。被端点联动连接的外部对象继续遵循原有联动规则。
- 端点精确映射；handle 的方向跟随透视映射的局部切线。Smooth 两侧保持反向共线。圆弧接笔仍由原关系重算，不将它烘焙成普通曲线。
- 线宽、端点笔触距离、雾化宽度等样式数值保留；这是几何变形，不是把整个渲染结果当图片做透视。
- 显示区间跟随原曲线上的对应位置，重新计算目标弧长比例；保留 track/range ID、两端笔触和闭环跨零语义。圆弧上的标记按同一过渡弧内的弧长比例迁移。
- 变形框交叉、压扁、触及透视奇点或使已有圆弧退化时，保留最后有效预览，显示原因。

## Bézier 适配

四角定义矩形到凸四边形的 homography。普通 cubic 的精确透视结果一般是有理 Bézier，因此这里使用普通 cubic 近似，端点和切线作为硬约束，只拟合两侧正 handle 长度。

先用投影权重推导单调参数映射，再交替优化 handle 长度与曲线上的点对应关系。这样长衣领曲线不会为匹配不合适的参数进度而被拉歪。显示区间使用同一对应关系迁移。

顶部「采样拟合偏差」表示相对于理想投影的采样位置误差，使用 Drawing 的逻辑 px（250 px / 坐标单位），不是当前屏幕缩放后的像素，也不是解析误差上界。极强变形仍可能存在近似偏差，用户可减小变形或后续手调。

同一次工具会话的各角始终从开始时的源几何重新计算，避免连续拖四个角反复累积拟合误差。切换选择、重置框或结束后再次进入，以当前几何开启新的会话。仅保存最终几何；本轮没有新增姿态 Key 或持久 deformer 动画层。

# V0.12.39 — Drawing snapshots

快照保存当前绘制姿态；Recording 以后再负责整体位置 offset、yaw/pitch 绑定及插值。本版不生成录制 Key，不自动居中、不消除原有位移。

## 使用

绘制间顶部新增快照栏：

1. 正脸完成后，点击「保存为新快照」，命名「正面」。
2. 继续调整背景对齐、用四角变形和 A 工具修改曲线，再「保存为新快照」命名「近正面左视」。也可先保存同形副本，再编辑并「更新当前快照」。
3. 下拉框切换快照。若当前画布相对快照有修改，可「另存并切换」「不保存并切换」或取消。原快照不会被自动覆盖。
4. 「更新当前快照」明确替换所选快照；铅笔图标重命名，垃圾桶删除快照。删除快照保留当前画布。

保存、更新、重命名、删除、切换，以及「另存并切换」均为单次 Undo/Redo 操作。当前工作画布依旧参与项目自动保存；未存入快照不等于未写入项目。下载 JSON 包含画布和整个快照库。

## 保存范围

保存完整 Drawing Document，包括坐标、handles、绑定和接笔、笔触、显示区间、填充/雾化、图层与组合、名称、隐藏/锁定、深度 offset、镜像轴、背景图片及其位置/缩放/透明度。保留同一曲线、节点、区间的 ID，以便未来对应。

画布观察缩放/平移、当前工具和选择不属于姿态。几何本身的位置原样保存。背景图自己的移动/缩放则属于快照，便于不同参考视角对齐。

快照独立，不限制后续增删曲线，也不自动跨快照同步拓扑。未来插值需要按 ID 检查对应关系并明确出现/消失语义；不能假定任意两份快照天然可插值。

## 数据与性能

`LandmarkProject.drawing` 保留工作画布；旁路 `drawingSnapshots` version 1 保存命名检查点与 activeId。原有 Drawing Document version 3 不变，所有普通编辑命令无需复制整份快照库。

快照库内相同背景图片只保存一次；每份快照独立保存背景变换。普通编辑时归档库保持引用不变，自动保存复用其已序列化内容。快照中没有额外 deformer、yaw、pitch、录制 placement 字段。

## 单个图层从快照恢复（2026-09-25）

每个图层标题行新增回转箭头「从快照恢复图层」。点击后选择来源快照，确认「恢复此图层」。按稳定图层 ID 匹配，不依赖名称；未包含该图层的快照显示为不可选。适用于把微侧外发恢复到正面，再用四角变形重新调整。

恢复的是该图层的完整内容：名称、曲线/节点/handles、填充、偏移关系、组合、接笔、显示区间、端点笔触、像素笔触、显隐/锁定和深度 offset。当前层后来新增的内容会被替换，快照中被删掉的内容会找回。当前图层在列表中的位置不变；其他图层、参考图对位、镜像轴与快照库不变。隐藏/锁定内容同样恢复到来源状态。

这是当前画布的一次普通编辑，可一次 Undo/Redo。不会切换到来源快照，也不会自动覆盖当前快照；满意后「更新当前快照」才同步到录制间。来源快照始终保留。

跨层端点联动若仍重合则保留，不再重合则在确认弹窗提示解除，不拉动其他层。其他层的填充/偏移如果依赖本次要删掉的新增曲线，会在确认前提示，恢复后保留其对象并显示失效诊断。若来源对象已移至另一层，则阻止恢复并提示先移回，避免跨层抢占对象或改变其 ID。

# 组装间（多角度模型调整）— 清单（草稿，待 bowen / dot 过目）

来源：bowen 1792682677（30° / 60° 参考图 → 实测角度的手调文件 → 魔改 bench「组装间」，多个 yaw 角度一次调完，
限制加好，例如侧脸同一片的点联动）；眼睛只调球面框 yaw 和轨道位置（bowen 1792682066，dot 1792682093）；
31.5° 这类角度只是「相对当前模型的最佳匹配」，各部位对不上同一个角度时保留差异给 bowen 修（dot 1792682726）。

## 1. 它是什么

- 一个独立页面（face3d 实验分支的 viewer，和转头检视同一个服务 5192），不改 bench（core/v1）的代码。
- 编辑的是**模型**，不是一张画：模型 = 若干关键帧角度 + 每个角度的三样东西（下面 §3）。中间角度按现有规则插值，
  转头检视直接读同一份模型文件。
- 画面：一排面板，每个关键帧角度一格（例如 0 / 30 / 45 / 60 / 90，加上实测角度 31.5 这种），各自带自己的背景参考图，
  同一个比例尺。点一格就在那一格里调；其他格同时显示。

## 2. 文件

- 模型文件：`bench-tasks/组装间/model.json`（新文件）。从现在的转头检视数据（`侧脸平片` 那一版 + 眼睛表）初始化。
- 每次保存前把旧文件复制到 `bench-tasks/备份/组装间-HHMM.json`；不覆盖 bowen 的 `脸轮廓手调/` 里任何文件。
- 参考图：每个角度一张，按「统一缩放 + 平移」放好（不变形），位置记在模型文件里，组装间里只能显示 / 隐藏、调透明度。
- 转头检视加一个下拉项「组装间模型」读这份文件。

## 3. 每个角度能调什么（限制）

| 部件 | 能做的 | 不能做的 |
|---|---|---|
| 脸轮廓（近 2 远 3，5 根线） | 拖点（两边 handle 跟着平移）、拖 handle；两根线在一点顺滑连接的，拖一边 handle 另一边跟着转（同 bench 的「手柄跟随」） | 加点、删点、断开连接 |
| 锁点：颅顶、下巴、耳点、颧骨点、太阳穴点 | 只能横移（高度固定在 −82.2 / 62.3 / 25 / 25 / −5.67） | 竖向移动 |
| 侧脸平片 | 拖平片上任意一个点（眉心、鼻尖、上唇、下唇）**只能横移**；整片按同一个角度联动：这一格的平片角度 θ 由拖的那个点反推，其余点 x = d·sin θ 一起动 | 单独挪某一个点；改高度 |
| 侧脸的颅顶、下巴 | 跟脸轮廓共用，随脸轮廓走 | 单独拖 |
| 眼睛（两只，各两个量） | 左右拖眼睛 = 改轨道角 ψ（眼睛中心沿绕轴的圆走）；另一个控件（滑条或滚轮）改球面框 yaw φ | 改眼角、眼宽、高度；改球半径（固定 40） |

- 平片上点的深度 d（90° 时的横坐标）和高度不在组装间里改：改平片形状要回 90° 那一格，在 90° 拖点 = 改 d（这是唯一能改 d 的地方）。
  ——这一条需要 bowen 确认（见 §7 问题 2）。
- 0° 那一格：侧脸是正中一根线，平片角度固定为 0，不能拖；眼睛 ψ、φ 固定为 0。
- 90° 远侧眼看不见，组装间里画灰线，可以调（它决定 60–70° 的过渡，dot 1792682311）。

## 4. 关键帧和插值

- 关键帧角度是一张有序表（0 … 90，正向；负角度照旧镜像）。新增一格 = 选一个角度（例如实测的 31.5），
  三样东西先按当前插值填好，再调。删除一格 = 那个角度回到插值。
- 脸轮廓：相邻两格之间点和 handle 线性插值（和现在的转头检视相同）。所有格里线和点的编号一致（同一套 5 根线）。
- 侧脸平片：θ 按关键帧表分段线性。
- 眼睛：φ、ψ 按关键帧表分段线性（现在的表：近 0/16/46，远 0/63.8/95；ψ 近 0/43.35/90，远 0/41.38/90）。

## 5. 操作流程（每一步都要能撤销）

1. 打开组装间：读模型文件，每格画模型 + 参考图；转头检视同步可拖。
2. 选一格 → 拖脸轮廓点 / handle、拖平片点、拖眼睛、调眼睛 φ；锁点只横移，平片整片联动。
3. 撤销 / 重做：⌘Z / ⇧⌘Z，跨格共用一条历史。
4. 保存：写模型文件（先备份），转头检视刷新即可看到。
5. 新增角度格：输入角度 → 生成一格 → 放参考图。

## 6. 验收（bowen 用真实操作，dot 核对关系不被破坏）

- 拖平片任一点后，同一格其他平片点仍满足 x = d·sin θ，高度不变；其他格不变。
- 锁点拖动后高度不变；侧脸的颅顶 / 下巴跟着动。
- 眼睛只能改 ψ、φ；保存再打开数值一致；转头检视里连续拖动没有跳。
- 保存不碰 `脸轮廓手调/`；备份存在。

## 7. 要 bowen 定的

1. 组装间做成独立页面（推荐，不动 bench），还是改 bench 本体？
2. 侧脸平片的形状（深度 d）只在 90° 格里改，其他格只改整片角度 θ —— 这样对吗？
3. 眼睛的 φ 用滑条还是滚轮？（推荐滑条，数值看得见）

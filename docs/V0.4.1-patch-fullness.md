# V0.4.1 — Patch Fullness

## 使用
选中侧边栏或 3D 检查中的 Patch，在曲面面板调「面凸度 / Fullness」。
范围 -100%…+100%，默认 0%，支持归零。选择镜像侧显示同一 canonical 值。
关闭「显示 Patch」时仍可设置，重新开启后求值。

## 数据与管线
SurfacePatch 增加可选 fullness:number；范围 [-1,1]，仅 canonical/self-symmetric 保存。
旧项目缺省等同 0。新增/修改 Fullness 使用 landmarks-0.4.1。
保存不含 normal sign、位移顶点、内部控制点或派生网格。
SemanticLandmark → Planar CurveEdge → BasePatch → Fullness → tessellation/render。
未加入 Smooth，也没有改动 Curve、View Lock、symmetry 的原有数学。

## 数学
Quad：B=[16u(1-u)v(1-v)]²。
Tri：B=[27(1-u-v)uv]²。
S=S0 + fullness × 0.15 × Lpatch × B × Nout。
Lpatch 为边界弧长的中位数（沿用通用 Bézier arcLengthLUT，固定 512 段，独立于显示精度）。
FULLNESS_SCALE=0.15 集中在 domain/patches/fullness.ts。

BasePatch 公式不变；零值直接走旧 evaluator，完全不计算 Fullness 法向。
采用一阶 forward automatic differentiation 求 BasePatch 的 du/dv，包含 self-symmetry 参数映射。
法向来自 cross(du,dv)，不是 tessellation 法向。
边界直接返回原 BasePatch；平方 bubble 的值和一阶导数在边界均为零。

## Head Origin
固定 O=(0,0,0)。quad 中心或 tri 重心判断 dot(N,P) 符号。
中心退化或点积过小时，用固定内部采样点平均。仍然只确定一个 canonical Patch 级 sign。
准备后的 evaluator 缓存到 immutable project / patch ID，所有视角和 LOD 共用。
每次 source project 更新重新派生；不随相机或网格采样方向翻转。
仍不能可靠判断时非零 Fullness 报 INVALID 并保留 source；零值保持旧 Base。
此规则适用于原点位于合理内部的头壳，不是通用凹壳 orientation solver。

## 镜像
先 evaluate canonical Base + Fullness，再对最终世界位置 mirror。
follower 不独立解释 Fullness 或 outward。
self-symmetric Base 的参数对称映射保留，bubble 对对应参数置换不变。

## 状态与 UI
一次连续 slider pointer gesture / 按键连按作为一步 geometry Undo；归零单独一步。
Undo/Redo 保留仍存在的 Patch 选择，参数面板不会消失。
Opacity 和显示精度沿用 display state，Undo 不回滚它们。
Fullness 控件继承 Patch panel 的 UI keyboard context。
2D、缩略图、3D、深度遮挡及 3D 面 picking 共同消费最终 tessellation。

## 验证与限制
单元测试覆盖 tri/quad/self 的零值精确兼容、解析微分与差分对照、boundary position、
boundary first-order behavior、正负方向、尺度、world mirror/self symmetry、LOD 无关、
source edit、保存加载、非法数值、退化恢复及 Head Origin 歧义。
浏览器验证拖动单步 Undo、Redo、归零、镜像入口、display 不进 history、reload、
2D path 和 3D 图像变化、关闭显示后修改再开启。

这是 interior fullness，不修相邻 seam，不保证任意折叠 BasePatch 的法向连续。
退化内部法向可能使非零 Fullness INVALID，记录保留；恢复 source 或归零可恢复。
极低采样只近似显示连续曲面；不会改变 evaluator 的几何定义。

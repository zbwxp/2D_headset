# 录制间转视角性能

2026-09-25，用「基础脸模·正面·微侧.json」的两套完整矢量快照，在独立 localhost 测试页测量 40 个不同角度（0°～15°）。包含头壳参考、两个预览、轮廓雾化和雾化填充。

| 项目 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 姿态求值均值 | 8.67ms | 2.92ms |
| React 渲染均值 | 128.44ms | 30.29ms |
| 显示帧间隔均值 | 143.33ms | 37.92ms |
| 显示帧间隔 P95 | 183.4ms | 50.1ms |

本机平均约从 7fps 提升到 26fps。数据来自开发构建、含 Profiler 的实际浏览器测量，不是对所有设备的帧率保证。

主要耗时来源：每角度重新生成雾化位图，Canvas GPU → CPU 像素读回；相同曲线反复构造弧长表；每个区间锚点再次混合全部区间；两侧预览分别构造同一套 SVG。

改动：

- 轮廓/填充雾化使用适合像素读回的 Canvas context；转动时降低雾化栅格采样，停止 160ms 后恢复原完整采样。高斯距离、宽度、浓度、形状和内外侧语义不变。
- 两侧窗口通过 SVG `use` 共用绘制树，红色冻结参考和头壳仅留在左侧。
- 相同支撑姿态共用权重和区间混合结果，避免重复复制不变元数据。
- 2D cubic 用相同 de Casteljau 数学及同样的展平误差阈值，减少中间 3D 数组分配；按数值缓存弧长表，缓存与可变编辑数据分离。
- 头壳只在画布尺寸改变时重新分配 WebGL 缓冲。
- 转视角事件按显示帧合并，结束时立即应用最新位置。

验证包括完整脸模冻结发丝/填充/遮挡回归、采样与旧数学结果对比、可变控制点缓存失效、事件合并与最终角度、雾化低采样及恢复完整精度。

复现页面：`http://localhost:5174/artifacts/recording-performance/view.html`。使用独立测试 origin，不在用户主项目标签页加载测试数据。运行「Benchmark with mist」；测试页不把测试模型写入自动存档。精确结果见同目录 `results.json`。正式绘制间继续默认使用完整雾化精度。

## 第二轮：矢量显示流程（2026-09-25）

保留原始 cubic 控制点和完整精度的弧长、显示区间、圆弧裁切计算；仅改变显示外轮廓的支持点密度。`displayInkSampling` 在普通尺度使用 0.05 px 的中心线展平阈值，直线最低细分从 32 降至 16，收尖支持点从 24 降至 12；放大时分档增加精度。源段两端保留原始相邻采样，避免有限差分法线在接缝处变化过大。中心线阈值不是整个笔触外轮廓的严格误差保证；完整脸模在正面、中间态、微侧的双向边界距离回归要求 <0.25 px（250 px/单位）。

- 等宽、无需拆深度片段的墨线直接使用原生 cubic 描边，不再额外计算其密集外轮廓。雾化遮罩与深度片段仍显式索取外轮廓。
- SVG 显示坐标保留到 0.001 显示单位；原始作者数据、录制插值和保存精度不变。
- 图层/笔画/深度批次按结构内容缓存；修改连接、父级、顺序、深度 offset 等会失效，单纯插值坐标复用。缓存只保存 ID 和派生顺序，不保留文档历史。
- 两个预览继续共用一套绘制树。Drawing Room 同样采用显示采样优化，并随缩放加密。

本轮优化前无雾化 22.92 ms/帧；优化后交叉运行三组、每组40个不同角度，结果如下。每轮角度略微错开，避免用整套相同角度反复命中位图缓存来制造加速。

| 模式 | 三轮平均帧间隔 | 单轮均值范围 |
| --- | ---: | ---: |
| 无雾化、保留普通填充 | 17.64 ms | 17.08–18.75 ms |
| 仅4个眼部雾化填充 | 17.21 ms | 16.67–17.50 ms |
| 原有全部雾化 | 28.89 ms | 28.75–29.16 ms |

两种前者差异在测量波动内，不代表填充是零开销或能加速；此资产部分填充只是平移，可自然复用缓存。眼部4个填充为左右虹膜黑雾、左右下缘白雾。这是交互时已有低栅格精度模式的耗时，非完整精度冷导出耗时。P95仍包含约33ms的丢帧，不承诺稳定60fps。

单套绘制树的 SVG 路径字符串从约619,757字符降到约150,900字符，减少约76%。浏览器已对照整体和放大眼睑/发梢。构建通过；706 tests passed，原有5个建模测试失败不变。

复现：测试页 `Compare ×3`；数值见 `artifacts/recording-performance/results-vector.json`。画面对照：`artifacts/recording-performance/quality.html`（左为原精细显示，右为优化后）。以上测试页不写入自动存档。

后续效果方向已确认但本轮未实现：轮廓效果应模拟 pixel 线稿的窄灰阶抗锯齿边缘，约3–5个灰度层次，保留实心笔画，不再扩散成宽雾或粒子；瞳孔的内/外雾化填充是另一种效果，继续保留。本轮没有修改雾化参数与效果定义。

## 第三轮：线条像素笔触（2026-09-25）

上节的后续效果现已实现。线条原「轮廓雾化」改为「像素笔触」：直接处理墨线边缘，保留黑色主体、收尖和接头，不再在清晰矢量线下面叠模糊图片。瞳孔/虹膜 `FillMist` 完全独立，本轮未改。

- 浏览器 SVG filter：固定低频微位移 → 窄高斯软边 → 五个连续插值的 alpha 灰阶控制值 → 与原墨线少量混合保住细线。不是喷枪/颗粒，也不强制量化为只有五种灰度。
- 参数为软边宽度 0.25–3 逻辑 px、笔触强度 0–100%。默认 1.25 px / 75%，默认不开启。软边实际扩散还受线宽限制，防止 1 px 细线化成灰雾。0 强度直接跳过滤镜。
- 宽度随画布缩放；微位移固定种子、使用墨线局部坐标，平移不重新随机。没有逐帧 Canvas 读回、逐像素循环或 PNG 编码。
- 同一笔相同设置共用一次效果；混合设置用既有 depth/memberInk 分片，保持全笔收尖与 CUSP/ARC 接头的分配。只改变绘制外观，不改 geometry、fill、picking、depth offset、显示区间。
- 存储仍在 curve/offset.mist，新增 `mode: "INK_EDGE"` 表示新参数。旧未标记存档在求值时映射到有限软边宽度/强度，加载不改写原文件或快照；编辑该效果后显式写新模式。

同一测试页面交叉三轮，各40个不同角度：

| 模式 | 平均帧间隔 | 单轮均值范围 |
| --- | ---: | ---: |
| 无效果 | 18.75 ms | 17.92–20.00 ms |
| 仅4个眼部雾化填充 | 18.89 ms | 18.75–19.16 ms |
| 新像素笔触 + 眼部填充 | 21.94 ms | 20.83–23.75 ms |

与上一轮原有全部雾化 28.89 ms 相比，本次约22 ms；不同测量批次有负载波动，不能把差值全当净算法耗时。新效果仍有浏览器滤镜成本，P95为33–50 ms，不承诺稳定60fps。只开填充与全开新效果每40帧均约40–43次 PNG 编码，全部来自未改动的眼部填充，线条自身为零。

结果：[results.json](../artifacts/ink-edge/results.json)。视觉对照：[像素笔触](http://localhost:5174/artifacts/ink-edge/view.html)，可看整体、眼睑、发梢和不同视角。测试页使用独立 origin，未在用户主项目载入测试数据。

验证：39项相关测试通过；生产构建通过。全套710通过、5个原有建模失败，另一个建模测试并发运行超时，单独重跑通过。浏览器验证单线控件、一次Undo/Redo、JSON往返、零强度、隐藏描边；E2E用例已更新，未另行运行整个Playwright套件。

# 二次元头壳结构整理稿

本稿基于侧边浏览器导出的实际项目整理。原始项目完整保存在 original.json；head-shell-study.json 是可直接载入编辑器的修改稿。由 35 点、31 线调整为 43 点、54 线。

## 造型含义

前边界表示正面脸转入斜面带的位置，后边界表示斜面带转入侧脸的位置。它们是造型控制线，不是逐一对应真实骨骼棱线。“45 度脸”表示过渡区域，不要求固定 45 度角，也不要求是一个平面。

| 层次 | 前边界 | 后边界 |
|---|---|---|
| 额颞层 | 额颞转折点 | 颞侧转折点 |
| 颧颊层 | 颧颊转折点 | 颧弓侧后点 |
| 下颊层 | 下颊收束点 | 下颌角定位点 |

两条纵向边界各自向下巴收束，三个层次各增加左右对称的横向桥。顶部使用圆弧连接颅顶与前、后边界；后脑连接后边界。颈口由前中点、左右侧点、后中点组成闭合线环。原“喉结”改为颈口前中点，避免把接口控制点误解成喉部解剖标志。

AI 参考图继续作为审美参考。本轮保留原图及其位置、旋转、缩放，将透明度设为 25% 并锁定以方便检查线框；没有生成新图或增加视角，也没有将各图当成一致的精确正交测量。当前位置和弧度是可继续调型的研究稿。

眉、眼、鼻、嘴使用“五官占位”前缀，耳廓使用“耳廓占位”，耳根使用“耳部接口”。保留它们供比例与资产定位使用，没有制作独立五官资产。眉尾与外眼角的深度也作了调整，使其更贴近面部正面区域。

## Smooth 和连接

取消了颅顶、前边界额颞、前边界颧颊、下巴处共 4 条 Smooth source record（包含对应镜像实例）。当前空间 Smooth 会裁去共享点附近的 source，最终曲线不经过该点；用于多分支节点时，横向桥会看起来与纵线脱开。因此这些节点保留真实相接的 Corner，再用各条 source 曲线的弧度控制轮廓。剩余五官、耳廓的 5 条 Smooth source record、9 个解析实例均有效。

黄色中轴 guide 的显式顺序为：后颈 → 后脑 → 颅顶 → 额部下端 → 鼻根 → 鼻尖 → 鼻底 → 上唇中点 → 口裂中点 → 下巴 → 颈前。它仍是开放参考线，不是曲面边界。

## 校验与范围

通过项目解析及 JSON 往返、点与曲线镜像一致性、中轴顺序完整性、端点引用、有限数值、source 平面残差及颈口闭环检查。详细数值见 validation.json。已在编辑器检查斜视、侧视、纯俯视和 3D 显示。

本轮只修改项目数据，没有修改软件源码、View Lock、投影、对称或 Smooth 算法。没有进行全网络连续曲线自交的完备证明；线框尚不代表已经可直接填充的 watertight 曲面或 Patch 网络。后续应先继续审视脸宽、斜面带宽度和耳根深度，再确定填面拓扑。

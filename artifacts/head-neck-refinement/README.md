# 头壳调整：前脸转折与双层颈环

本轮基于浏览器当前几何状态 1619E36B；备份 before.json 与该模型状态码一致，保留了用户最近抬高后颈点的调整。画布缩放等展示状态不包含在模型状态码中。结果 refined.json 已载入编辑器，状态码见 validation.json。

## 本轮修改

- 左右后脑至颞侧弧：使用平面 Bézier 控制柄形成圆润的后侧横弧，未增加中间点。纯俯视可清楚检查该弧。
- 前脸边界：额颞/颧颊/下颊分别向前调整到 Z=0.67/0.70/0.63，X、Y 保持。没有把颅顶一同向前推；相连曲线通过既有 endpoint frame transport 跟随。中部五官占位保持。本轮追求较平的面壳及可辨识的斜面带，但没有曲面，不能保证最终曲面平坦程度。
- 新增头颈交界·颏颈转折点、左右头颈交界·侧向连接点、颈部接口·后中点，共4点。保留原后颈点作上环后中点。
- 上环与下环各由4条 Bézier 边组成，分别经过前中、左侧、后中、右侧，均闭合。两环通过前、后、左右4条纵线连接。
- 原下巴直连颈前改为下巴到颏颈转折的弯曲下颏轮廓，再从该转折向下连接颈前。下颌侧向连接落到上环侧点，避免直接跨至下环。
- 下环仍复用原前中点和左右侧点，补齐独立后中点。没有额外加入下巴下表面点。

总数由43点54线变为47点62线。所有新增点都有明确连接用途。中心线 guide 仍为显式开放序列：下环后中点→上环后中点→后脑→颅顶→脸部中轴→下巴→颏颈转折→下环前中点。

# 二次元线稿匹配实验

已将 matched.json 载入侧边浏览器。before.json 是本轮操作开始时从浏览器保存的备份。

## 结果范围

沿用 43 个语义点、54 条结构线，全部 UUID、端点连接和中心线顺序保留。本轮没有新增点或线，没有修改编辑器源码，也没有添加 View Lock 或改变约束数学。

正面原稿是主要匹配目标：拟合头顶外轮廓、眉弓、眼裂、耳廓和下颌。侧面原稿主要约束颅顶、前额、后脑及后颈的深度轮廓；斜视原稿辅助调整五官、耳廓深度。五官仍是占位线框。

没有生成新的参考图。保留原始线稿像素，只对参考图显示做了对齐：正面水平中轴对到图像 x=297；右30度图通过图中颅顶/下巴两点与模型投影做二维相似变换。此变换只调整参考图位置、旋转、大小，并不证明画稿是严格的30度正交视图。其他参考图的原有位置/旋转/大小保留；透明度统一为65%，并锁定。

## 如何看叠图

front-comparison.png / right30-comparison.png / side-comparison.png 均为左：原模型，右：匹配后模型。两边使用同一张未改像素的原参考、同一套最终参考图变换，比较的是几何投影变化。

青色为五官占位，绿色为耳部，洋红色为部分头壳线，金色为内部结构/接口线。全部曲线通过当前 resolveNetwork 求值，局部 Smooth 使用真正的五次控制点采样显示，未用 source 曲线替代最终平滑结果。由于展示的是透明线框，背面的颅壳/后颈也会投到正脸上，这些交叠不表示脸上新增了相应墨线。

现有前后两条面壳边界及横向桥里，有些在线稿中并未显式画出；这些属于根据体积关系推定的结构线，不能算作描合墨线的成绩。

## 实际限制

正面匹配较好。斜视仍保留双眼高差、部分眉形和脸颊轮廓误差；侧视五官与耳廓不能同时贴合另外两张图。这可能包含绘画透视、表情/造型变化、实际相机角度及当前拟合选择的误差，不能仅凭这次拟合断言原图画错。

本轮对称模型共用一套三维点，不能逐视图独立扭曲。优先保证正面，斜视五官/耳廓取较高权重，侧面五官只作弱深度参考；侧面颅壳轮廓仍单独匹配。因此本次不是“所有视图完美一致”的结果。未生成曲面，未证明整个网络无自交或可直接填面。

局部 Smooth 范围改为耳部0.055、其余0.035，减少裁掉眼角/耳部转折造成的偏离。9个解析 Junction 实例均有效；原记录UUID和配对保留。
